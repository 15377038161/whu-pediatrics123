## 四、能力边界（官方 SDK 实测，精确标注）

已证实入口：

| 入口 | 返回 | 限制 |
|---|---|---|
| `KnowledgeClient.recall({query, knowledgeBaseIds, topK, recallThreshold})` | `{results: [{title, content}]}` | **仅两个字段**：title（实测多为空串）、content（片段文本）。无文档 ID、无文档级全文、无分页遍历 |
| `KnowledgeClient.list()` | 库元数据（id/baseName/description/owner 等 15 字段） | 仅库级信息，无文件清单 |
| 图片库 recall（3821625） | 同样仅 `{title, content}` | content 为 OCR 文本元数据（DICOM 描述等），**不含图片 URL**；图片 URL 仅偶发存在于文档库片段文本内 |

**未支持（本轮实证无法获取）**：
- 知识库全文导出 / 按文档 ID 获取完整 TXT 正文——SDK 无此方法（方法枚举实证：`recall`/`list`/`unwrap`/`buildPlatformUrl`）
- 图片库原图 URL 直连——图片库 recall 不返回 URL
- 文件批量拉取 / 媒体元数据结构化访问——无对应 API

最小内置替代路径（已在 `docs/教师审核导入方案.md` 记录，未实施批量导入）：教师经 `/teacher/case-drafts` 逐例导入结构化 JSON → 预校验（字段完整性/来源/脱敏状态）→ 草稿保存（`case_draft_imports`，教师独占 RLS）→ 真实教师审核后入库。**该路径未实施批量执行；53 来源需教师逐例审核，召回片段仅作定位辅助。**
