# UI 设计规范

## 1. 视觉方向

“珞珈书院 × 儿科临床工作台”：使用珞珈山树影、校舍屋脊、听诊波形、生长曲线和纸本记录纹理。查体场景采用原创仿真虚拟患儿与写实器材素材，人物保持真实年龄比例、正常着装和临床环境；部位通过可访问热区叠加，不使用失真照片或高饱和卡通主视觉。界面明确标注“虚拟标准化患儿”，避免与真实病例影像混淆。

## 2. 颜色

- 主墨色 `#173C3C`：导航、病例工作台和核心信息。
- 陶砖红 `#AA493A`：主操作、重点状态和武汉大学建筑语义。
- 纸本米白 `#F7F4ED`、暖白 `#FFFDF8`：主背景和内容面。
- 苔绿 `#678578`、浅青灰 `#D9E7E3`：临床辅助状态。
- 警示色 `#A53F3A`、成功色 `#2C6D58`：只用于状态，不作装饰。

不得新增默认紫色渐变、玻璃卡片瀑布、荧光描边或无业务含义的 AI 星光。

## 3. 字体与尺寸

- 中文正文：微软雅黑 / 苹方 / Noto Sans CJK，16px，行高 1.6。
- 页面标题：宋体语义字体，移动端 27—42px 响应式。
- 分区标题：20px；组件标题：16—18px；辅助说明：12—14px。
- 所有输入正文不得低于 16px，避免移动端自动缩放。

## 4. 组件

- 触控目标最小 `44×44px`。
- 按钮统一 12px 圆角、44px 最小高度；主按钮陶砖红，次按钮暖白描边。
- 表单字段统一 13px 圆角，标签位于字段上方，错误信息紧邻字段或阶段容器。
- 弹层、抽屉和工作区圆角 18px；不对每段文字再套卡片。
- 所有业务页提供返回或首页路径；删除类按钮仅在存在可删除对象时出现。
- 体检器材使用统一光线和视角的写实产品图；器材名称始终保留，选中状态同时通过边框、文字色和 `aria-pressed` 表达。缩略图只承担器材辨识，不替代器材与部位规则校验。
- 病例选择页同时呈现年龄、性别、难度和审核状态。首版至少包含男童与女童病例；后续新增病例沿用相同卡片和训练容器，不新增平行页面。

## 5. 响应式

- 320—699px：单任务纵向流，底部主导航；训练记录以可折叠区域呈现。
- 700—1023px：双列或宽屏单列，保持同一组件和信息顺序。
- 1024px 以上：左侧导航；临床工作台重排为操作、患儿、病例记录三列。
- 不维护手机/电脑两套页面，不允许出现横向滚动和被键盘遮挡的固定输入框。

## 6. 动效与无障碍

- 登录背景为无声 8 秒循环，提供 WebM、MP4 和 SVG 海报。
- 患儿只使用轻微呼吸、表情和局部动作；不模拟惊悚或夸张病理效果。
- `prefers-reduced-motion` 下停止循环媒体和动画。
- 所有热区提供文本标签、键盘操作和可见焦点；颜色不作为唯一信息载体。
