# 你需要怎样交给 Coder

打开现有“武大儿科学智能体”项目，不新建空项目：

https://robot-hs.chaoxing.com/coder/aiWorkspace?projectId=034d70761314b75d22cbf4fa3740fd07

1. 如果本次对话已经显示“67例代码及私有运行资料”的新消息和全部附件，就直接等它执行，不重复发送同一任务。此处的“已接收”不代表“已合并、验收或发布”。
2. 若还没有收到，在Coder聊天输入框左下点“更多工具”→“上传文件”。进入本机 `D:\coze\儿科学\deliverables\Coder接入67例_20261107\uploads`，一次选中该目录内全部7个ZIP和1个JSON校验清单并上传。不要上传.env、密钥、整个工作区或旧的20261103实施包，也不用上传384MB的Word总包。
3. 等附件全部上传成功，再发送同目录外的 `01_复制给Coder.txt` 内容。完整执行要求已在代码ZIP内，Coder先读START_HERE.md和执行提示词再合并。
4. 正常应先看到它核对云端HEAD、解压包、比对文件和67例源版本，而不是直接覆盖仓库；随后是合并、安装私有数据、真实模型与手机/桌面流程验收，最后才发布并给出地址。
5. 如果提示文件过大，只上传已经拆好的分包，不压低图片质量、不重新拼成大ZIP。上传失败仅重传失败包；Coder收到全部分包前不切换病例索引。若积分不足，在平台按自己的需要补足后，在同项目发送“从现有进度继续本次67例接入，不重复导入已完成部分”；不要把额度不足当成已部署。
6. 如果需要真实扫码，打开Coder的预览或它给出的实际站点，按原有超星入口自行扫码；正常进入学生或教师端后，在Coder回复“已完成当前预览的登录，请继续真实流程验收”。不要在聊天粘贴密码、access_token或API密钥。若回到登录页，先让它说明回调/会话错误，不用测试身份绕过。

完成后，你可以先新建一例训练，连续问“用过什么药？”→“吃了以后呢？”，然后在查体里依次选头面颈部→额部→额温枪。最后申请检查、提交病历和诊疗，查看逐点评分及检查复盘。旧会话仍保留旧版本，不能用旧会话是否变样判断新包有没有接上。

模型服务未配置时需要Coder复用平台环境中已有的服务配置；如确需新增秘密，只在平台环境变量/密钥设置中输入，不能把密钥发给聊天助手。医学补充仍标为未医学审定，不将其当作现实患者处方。
