# GitHub到Coder的使用方式

代码和内容由Codex完成，Coder只运行服务器。一般不需要用户重复搬运代码或让Coder继续编写功能。

Codex完成本地检查后把代码上传GitHub，并向现有Coder项目发送分支、完整提交SHA和具体运行指令。Coder拉取、构建、启动预览，Codex再核对页面与接口。现有项目地址：

https://robot-hs.chaoxing.com/coder/aiWorkspace?projectId=034d70761314b75d22cbf4fa3740fd07

如果需要用户核对体验，打开Coder预览并刷新，先选任意器材，再点击人物大部位、局部图检查位置；错误搭配应得到明确提示，正确搭配得到已释放的本例所见及反应，记录可用于后续判断和病历。旧会话仍保留旧资料版本；新代码出现不表示新版病例数据已自动启用。

需要真实登录时使用现有本平台或超星官方入口，不在聊天发送密码或令牌。运行失败由Coder返回具体日志，Codex修复后重新上传；不要让Coder重写页面或猜接口。预览更新不代表线上发布。
