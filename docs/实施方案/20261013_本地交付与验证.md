2. 本轮防透题覆盖应用API、公开目录与工作台。现有数据库RPC以学生JWT调用（例如list_tests），数据库直连的列权限/RPC可见性需在实际租户另行复核；不能把UI/API投影称为正式防作弊机制。
3. 随机教师病例仅从当前服务端可读取的完整资料中选择，纯数据库导入但未被安全恢复到可读事实的病例暂不进随机池。待审核女童演示不进随机池。
4. 主诉来自受控病例记录，不等于所有53份资料已经完成临床审核。查体按明确原文片段归类，无法对应方法的资料不开放结果，需教师补充；不自动合并不同患者或补造正常值。
5. 仰卧图为教学示意，解剖页为二维部件示意，不交付真实儿童3D模型。语音没有录音、播报和HTTP接口。
6. 课程/门户挂载、公众号发布、真实平台发布仍需单独授权。历史文档中的日期、旧故障保留为历史证据，由本记录说明当前本地状态。

## 本地复验

```powershell
pnpm install --frozen-lockfile
pnpm exec next typegen
pnpm validate
pnpm build
```

开发预览显式运行`pnpm exec next dev -H 127.0.0.1 -p 8765`，不使用含Linux变量语法的旧dev命令。生产模式在独立PowerShell进程设置HOST=127.0.0.1和DEPLOY_RUN_PORT=8770后运行`node dist/server.js`。构建时先停本轮测试服务，避免共享.next缓存冲突。

UI复验：安装Python Playwright及Chromium后，运行`pnpm exec tsx scripts/create-ui-fixtures.ts`，再运行`python scripts/verify-ui.py --base http://127.0.0.1:8765`（生产服务改8770）。脚本仅允许回环地址并拦截API为合成响应，不连接真实服务或修改认证。
