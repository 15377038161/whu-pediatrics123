# 首页病例库任务书：审核意见处理说明

日期：2026-10-21。依据：用户粘贴的外部审核意见。未另外调用任何外部模型，未假定这些意见全部正确。

修订文件：[首页病例库全流程审核任务书 v1.1](20261021_首页病例库全流程审核任务书_Claude.md)。本次仅改文档，不执行其规划中的代码、数据、部署操作。

| 意见 | 处理 | 采纳或不采纳理由及落点 |
|---|---|---|
| 1 试用隔离不明确 | 采纳目标，调整实现建议 | 第17节补充环境选择与身份/API/媒体负测。独立域名、feature flag、环境变量、trial_batch本身不是访问控制，不强制新增这些机制 |
| 2 剂量未经老师确认不得试用 | 部分采纳 | 不采纳“老师预审才能发布”，与用户明确的先整批教师试用相冲突。第16节要求重点提示、专业依据、适用条件及确定性核对；依据不可靠时不输出精确结论，不用于精确评分 |
| 3 版本规范缺失 | 采纳并修正方案 | 第18节区分会话事实版本、完整内容摘要和可读发布标签，补触发、反馈定位、回退与保留规则。不能直接替换现有版本字段，也不无限期保留敏感数据。已核对当前documents哈希算法的覆盖缺口 |
| 4 医学补充与试用循环依赖 | 部分采纳 | 有依据、内部核对、教师医学确认是不同状态，并无必须相互等待的循环。第16节分级核查，但不重新引入强制老师预审门槛 |
| 5 材料使用条件事后处理 | 采纳 | 第20节增加停止分发、引用定位、派生物/缓存检查、替换、总账记录及复验。撤文件与撤页面链接分开；不承诺已下载副本可全部收回 |
| 6 通过与发布语义混淆 | 部分采纳 | 文首统一术语及四个独立状态。保留允许遗留项教师试用，不采纳“所有内容验收通过才能试用”，以免改变用户整批发布要求 |
| 7 降级不完整 | 采纳并细化 | 第19节逐环节降级。文字报告不等于完成阅片/听辨训练，降级必须调整相应评分；通用图不得假扮本患者影像 |
| 8 并发修改 | 部分采纳 | 快速清单及第21节记录基线和文件变化；必要时codex/分支或worktree。不机械定期rebase、不默认stash用户改动，分支不等于隔离共享私有材料 |
| 9 测试成本 | 采纳优化，不缩全量范围 | 第22节全量基本链＋逐例关键内容核对＋代表病例共用负测；加超时、重跑和模型调用预算。拒绝只深测少量病例便宣称全量完成 |
| 10 隐私标准 | 采纳并补足 | 第20节覆盖文字、图像、PDF搜索层、视频、元数据、派生物及响应。日期统一相对化/偏移，保留年龄和时间关系，不能简单逐个删日期破坏临床时间线 |
| 11 快速清单 | 采纳 | 放在第1节；环境变量只查存在性；仅对本次需要的迁移核对，不默认执行任何迁移 |
| 12 阻断预案 | 部分采纳 | 第21节按具体根因处理；不采纳无依据的30%阈值或缺料就放弃整批。模型连续3次同根因失败后停同类重复付费尝试，为执行预算而非医学/平台标准 |
| 13 量化指标 | 采纳目标，不采纳机械门槛 | 第22节用关键区域可读、目标事实覆盖、操作证据对应等指标。800×600、3项查体、7段统称病史不适合所有病例，且容易诱导凑数 |
| 14 内部引用和代码核对 | 采纳 | 第4节补具体控制函数；第13/17/18节区分已静态读取与未运行验证。后续执行时再次定位是必要的防漂移要求，不能删除真实性边界 |
| 15 术语混用 | 采纳 | 文首统一材料、媒体、资源接口及四种验收/发布记录，明确此次不设置老师预审门槛 |
| 16 完整填写示例 | 部分采纳 | 第23节增加诚实标注状态的合成使用卡；真正完整临床样板须在第二阶段读取实际原件并跑通后交付。此轮不能编一例看似审核完成的临床样板 |
| 17 工具链 | 作为候选，不直接实施 | 第23节声明建议脚本名不是现有命令，先复用已验证工具，再按真实重复成本增补；当前任务是文档修订 |
| 18 数据结构扩展 | 暂不采纳直接加列 | 尚未证明当前载体不足。第18/23节要求先核对契约和持久化需求，确需修改才新增迁移；避免teacher_approved和medical_verified同一递进枚举混淆状态 |

修订保留用户的核心决定：先完成全部病例的审核与补充，再整批供老师从学生实际流程试用，反馈后改；发布不等于医学审核通过。只有未明确的目标环境、访问边界或实际隐私/越权问题需要处理，不能凭审核建议另设全面预审审批流程。
