# 珞珈儿科智训｜老师需提供的材料清单

> 适用范围：首版开发、校内验收和智能体大赛展示。
>
> 建议总量：首轮共提供 **12 个病例**，其中 **1 个主展示金标准病例、5 个完整交互病例、6 个专项训练病例**。首版先用主展示病例打通全流程，再分批补齐其余病例。

## 一、病例材料（最重要）

| 材料 | 数量 | 用途 | 提交时间 |
|---|---:|---|---|
| 主展示金标准病例 | 1例 | 打通问诊、查体、辅助检查、判断、处置、沟通、OSCE评分和专项补练完整闭环 | W1第2个工作日前 |
| 完整交互病例 | 5例 | 扩充综合训练与OSCE，证明智能体可以复用到不同儿科病种 | W3结束前 |
| 专项训练病例 | 6例 | 分别训练病史采集、体格检查、检查选择、鉴别诊断、处置、沟通等薄弱能力 | W6结束前 |

### 推荐病例覆盖

- 呼吸/感染综合病例：3例，其中1例作为主展示病例。
- 消化系统病例：2例。
- 神经系统病例：1例。
- 新生儿或儿童保健病例：1例。
- 血液/免疫病例：1例。
- 传染病儿科特点病例：2例。
- 沟通或安全处置专项病例：2例。

### 每个完整病例必须包含

1. 基本信息：年龄、性别、身高、体重、就诊场景、陪诊家长身份。
2. 主诉与现病史：症状发生时间、演变、伴随症状、院外处理及效果。
3. 儿科特有病史：出生史、喂养史、生长发育史、预防接种史、传染病接触史。
4. 既往史、过敏史、家族史、流行病学史。
5. 患儿与家长的信息边界：哪些问题患儿回答、哪些问题家长回答、未问时不得主动透露什么。
6. 体格检查：生命体征、阳性体征、阴性体征、检查部位、器材、准备动作和正确顺序。
7. 辅助检查：可选择项目、标准结果、合理/不合理选择、结果解读。
8. 标准诊断、诊断依据、严重程度、至少2项鉴别诊断及排除依据。
9. 标准处置：一般处理、药物或非药物处理、隔离/报告/转诊、复诊和随访。
10. 家长沟通：核心告知内容、推荐表达、禁忌表达、风险告知和确认理解方式。
11. 常见错误：漏问项、错误器材、错误部位、错误顺序、过度检查、危险处置。
12. OSCE评分表：评分项、分值、关键步骤、一票否决项以及每个得分对应的行为证据。
13. 资料依据：教材、指南或共识的名称、年份/版本、章节或页码。

## 二、图片、音频和动画参考素材

| 素材 | 建议数量 | 老师需提供什么 | 研发处理方式 |
|---|---:|---|---|
| 典型体征图片 | 每个完整病例4—8张，共约24—48张 | 原图或教材/指南中的参考图、体征名称、适用年龄、正常/异常说明、来源与授权情况 | 统一裁切、脱敏或重新绘制成写实教学素材 |
| 辅助检查图片 | 每个完整病例2—4张，共约12—24张 | 胸片、CT、超声、心电图、血涂片等典型图及标准判读 | 制作可放大、可标注的检查结果卡片 |
| 听诊及临床音频 | 共8—12段 | 正常与异常呼吸音、心音、咳嗽/喘鸣等，并注明采集部位和临床含义 | 降噪、统一音量、绑定听诊器和身体部位 |
| 动作/体征动画参考 | 6—10组 | 张口、伸舌、呼吸起伏、胸壁凹陷、皮疹查看等动作的医学描述或参考视频 | 研发制作短动画；不要求老师亲自制作动画 |
| 身体部位示意 | 1套 | 需要开放点击的部位清单及每个部位可观察/可检查内容 | 制作儿童正面、背面及重点局部交互图 |
| 器材操作标准 | 8—10种器材 | 听诊器、体温计、血压计、压舌板、手电筒、叩诊锤等适用部位、准备和操作规范 | 制作器材图标、拖拽/选择状态及逻辑校验 |

### 素材硬性要求

- 图片建议提供PNG/JPG，原始分辨率不低于1600×900；局部体征尽量清晰、无遮挡。
- 音频建议提供WAV或高质量MP3，单段10—30秒，并注明采集部位和正常/异常标签。
- 所有真实病例图片必须去除姓名、住院号、检查号、二维码、医院可识别信息和人脸身份信息。
- 每项素材必须注明“自有授权、可教学使用、需重新绘制或仅供医学参考”之一。
- 没有可授权图片时，老师只需提供医学描述和参考来源，由研发重新绘制，不能直接使用来源不明的网络图片。

## 三、知识库需要老师提供的内容

| 知识库类别 | 建议数量 | 需提供内容 |
|---|---:|---|
| 课程标准与教学目标 | 1套 | 儿科学课程大纲、教学目标、重点难点、学生年级、应掌握能力边界 |
| 核心教材 | 2—4种 | 教材名称、版本、对应章节；仅提供具有教学使用权限的文件或扫描页 |
| 指南/专家共识 | 15—25份 | 与首批病例相关的最新版指南、共识、诊疗规范和感染控制要求 |
| 儿科问诊与查体知识 | 100—150条知识项 | 不同年龄问诊方式、必问项、体格检查步骤、器材、正常值和异常意义 |
| 传染病儿科特点 | 10个主题 | 传播途径、潜伏期、接触史、疫苗史、儿童表现、鉴别要点、隔离、报告和重症预警 |
| 沟通场景 | 20个场景 | 焦虑家长、拒绝检查、担忧用药、依从性差、预后沟通、风险告知等角色与触发条件 |
| OSCE量表 | 6套完整量表+6套专项量表 | 任务说明、时间、评分项、分值、关键步骤、一票否决、证据要求和复核规则 |
| 正常值与计算规则 | 1套 | 儿童年龄分层生命体征、血压袖带选择、剂量或体重相关计算口径、参考范围 |
| 临床安全规则 | 1套 | 危急值、重症预警、必须转诊/上报、感染控制和禁止继续操作的情形 |
| 武汉大学特色内容 | 1套 | 学院/医院教学理念、优势专科、典型教学方法、校徽校训等可授权品牌素材及比赛表述口径 |

## 四、角色和沟通脚本

每个完整病例请至少提供：

- 患儿角色卡1份：年龄、语言能力、配合程度、情绪、能回答和不能回答的问题。
- 家长角色卡1份：身份、知识水平、焦虑程度、主要诉求、隐藏信息、触发点。
- 标准问答不少于30组：问题意图、回答角色、标准回答、可接受表达、禁止主动泄露内容。
- 沟通冲突脚本至少2组：例如拒绝检查、担忧药物不良反应、要求不合理检查。
- 结束条件：学生必须完成哪些告知、确认或安全处理，场景才算完成。

## 五、评分与考核材料

- 课程现有OSCE评分表和历年考核站点说明。
- 每个完整病例1份综合量表，建议总分100分。
- 每个评分项必须明确“看到什么行为才得分”，不能只写“沟通良好”等主观描述。
- 一票否决项必须单独列出，例如严重违反感染控制、危险处置、遗漏危重征象。
- 提供3份教师人工评分样例，用于验证智能体评分与教师评分的一致性。
- 如有历年学生常见错误、扣分统计或教师评语，请提供脱敏版本，用于专项补练推荐。

## 六、教师与管理信息

- 课程负责人1名。
- 医学内容审核教师2—3名，建议覆盖儿科临床、传染病/感染和医学教育或OSCE。
- 最终医学争议裁决人1名。
- 虚构或脱敏的班级样例1个、学生样例20—30名、训练任务样例3个。
- 比赛官方通知、评分标准、演示时长、网络限制和设备要求。

## 七、建议的分批提交方式

### 第一批：W1，必须先交

- 主展示病例1例。
- 对应患儿与家长角色卡。
- 该病例问诊要点、标准诊断与处置。
- 对应教材/指南依据。
- 审核教师与最终签字人名单。

### 第二批：W2—W3

- 其余5个完整交互病例。
- 体格检查规则、器材使用规范。
- 典型体征图片、检查图片、听诊音频及授权说明。
- 辅助检查、鉴别诊断和临床路径。

### 第三批：W4—W6

- 6个专项训练病例。
- 20个沟通场景。
- 6套完整OSCE量表与6套专项量表。
- 教师评分样例和常见错误资料。
