# 全部病例开放与资料覆盖核对（2026-10-08）

老师提供的 Excel 清单含 54 个病种，实际资料含 53 个目录。登记保留两侧所有记录，共 70 条；其中 37 条完全同名，17 条只见于清单，16 条只见于目录。这是 70 条登记记录，不是 70 份互不重复的真实患者病历。

## 学生开放结果

全部 70 条教师记录和原有 2 个示例均可进入学生端，共 72 个入口。提供病种搜索、系统筛选、引导训练、沉浸式教学和 OSCE 练习。现有 OSCE、语音交互和 3D 实验室入口继续保留。

53 个原始资料目录全部接入；14 条清单异名或具体亚型通过 `src/domain/teacher-case-links.ts` 关联，页面明确显示实际使用的来源名称。因此 67 条教师记录有真实资料来源。亚型记录保持原始亚型名称，不扩大成整个病种的标准答案。

目前未找到独立资料的清单病种只有：新生儿脑梗死、支气管肺炎、格林巴利综合征。这 3 个入口开放自主研习，允许记录问诊、诊断、处置和沟通，但不能提供不存在的病史、查体或检查结果。

## 资料处理与教学行为

173 份 Word/PDF 与 1 份病例分享 PPT 均已提取可读文本，其中 19 份旧版 Word 已转换。4 段 AVI 已转换为浏览器可播放的 MP4。原始文件保持不变，教学文本与转码文件分别生成在 `knowledge/teaching-cases/`、`knowledge/teaching-media/`。

问诊按原病例病史检索事实，模型仅负责口语改写；没有资料时明确说不清楚。查体按原病例记录生成检查项目，先完成检查准备再解锁结果。检查列表按病例变化，缺失生命体征显示“未记录”，处置后不虚构生命体征改善。教师资料病例报告标明“过程完成度”，只评价环节记录，并在训练结束后展示原病例诊断、诊疗经过供对照；诊疗正确性由教师复核。

学生可以分页浏览全部资料，原先“前 80 项”的截断已取消。影像和音视频通过登录接口访问。文档对学生返回身份字段已隐去的文本，对教师保留原稿核对能力。自动文本处理会去掉姓名、住院号、身份证号、联系方式、地址等常见身份字段；媒体保持原内容，不声称已自动完成影像或音视频脱敏。

## 准备与运行

先将老师资料放入项目 `knowledge/儿科常见病/`，安装 Python 依赖、LibreOffice 和 FFmpeg。旧版 Word 转换程序支持 `LIBREOFFICE_BIN` 指定转换器路径。

```powershell
python -m pip install -r scripts/requirements-cases.txt
pnpm prepare:cases
pnpm validate
pnpm build
```

资料目录发生变化时，先运行 `python scripts/generate-teacher-case-catalog.py` 更新登记，再运行资料准备命令。命名对应关系在 `teacher-case-links.ts` 显式维护。

本地完整流程验收须在独立预览服务中进行，固定回答用于验证资料与事件链路，不消耗真实模型配额：

```powershell
$env:ENABLE_UI_PREVIEW='true'
$env:ENABLE_AI_FIXTURE='true'
$env:PREVIEW_SIGNING_SECRET=[Convert]::ToBase64String([Security.Cryptography.RandomNumberGenerator]::GetBytes(48))
pnpm exec next dev -H 127.0.0.1 -p 8876
```

另开终端运行 `pnpm verify:cases`。脚本仅允许 localhost 或 127.0.0.1，逐条检查病例创建、问诊、查体、辅助检查、诊断、处置、沟通、报告和学生资料读取，并验证视频 MIME 与分段响应。检查结果：70 条完整流程通过；67 条教师记录关联 53 个独立资料目录；4 个视频访问验证通过。真实模型效果不属于这次固定回答验收。

## 部署契约

代码包不包含原始知识库。目标运行环境应把完整 `knowledge/` 私有挂载，并配置 `PEDIATRICS_KNOWLEDGE_ROOT` 为该目录的绝对路径，目录下必须包含 `儿科常见病/`、`teaching-cases/`、`teaching-media/`。原件和衍生文本不提交公开 Git，不放入 `public/`。

`GET /api/cases/[id]/resources` 与 `GET /api/cases/[id]/resource?path=...` 要求登录学生或教师，未登录 401。文件读取仍校验实际路径边界，并支持 Range；学生读取 Word/PDF 得到教学纯文本，教师得到原文件。
