## 三端完整链路

### 学生医生

登录 → 查看系统预置测试 → 选择病例与训练模式 → 以医生身份自主输入问题 → 必要时发送“请患儿独立回答”“请家长暂停插话”或情绪安抚 → 查体 → 辅助检查 → 诊断与鉴别诊断 → 处置与安全计划 → 沟通 → 查看报告或进入专项补练 → 学习结束。

### 主管智能体与系统预置服务

预置病例、任务、模式、量表及异常行为 → 医学与配置审核 → 发布不可变任务版本 → 创建唯一病例会话 → 识别问题与上下文 → 根据患儿年龄、回答能力和当前情境动态安排患儿/家长作答 → 模拟正常或异常答题状态 → 校验学生干预 → 执行查体、辅助检查、证据链及安全规则 → 评价沟通 → 封存证据 → 生成个体报告 → 更新能力画像 → 会话完成。

### 教师只读学情端

登录 → 查看学生列表 → 选择学生 → 查看历次测试 → 进入只读权限边界 → 选择已完成测试 → 查看个人报告和分项成绩 → 查看逐轮答题记录 → 查看查体、检查、诊断、处置和干预过程 → 查询结束。

教师端不提供任务发布、任务编辑、参数修改、评分修改或医学审核入口。

## 关键分支检查

- 患儿不具备回答能力：由家长代答；具备能力时，由智能体动态组织患儿回答、家长补充或插话。
- 触发异常状态：可表现为答非所问、刻意隐瞒、长篇冗余、拒绝配合、负面情绪或缺乏医学认知。
- 学生发起干预：先校验适龄性、适用性与表达恰当性，再更新回答优先级、插话概率、情绪和配合度。
- 问诊未完成：独立侧向回路返回医生输入，不提前进入查体。
- 查体或辅助检查不符合规则：进入独立回退线路，修正后重新校验。
- 诊断证据不足：记录证据缺口；证据充分时确认诊断证据链。
- 触发危重、感染、禁忌或转诊规则：执行安全拦截并要求重拟。
- 沟通目标未完成：返回继续沟通；完成后才能封存会话证据。
- 存在薄弱能力：进入对应专项补练；否则直接更新个人能力画像。
