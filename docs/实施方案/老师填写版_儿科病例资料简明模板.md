## 2026-10-30 接诊交互补充（各病例统一填写）

本轮首例用于建立后续全部病例的通用模板。每个入口仍须独立验收；共享来源的别名/亚型写明关联，不能把主入口通过当作全部入口通过。原始材料无需重做，以下表格用于标明其对应关系。

### 查体操作与体位

| 检查方法或器材 | 学生应自行选择的部位 | 允许体位（站立／仰卧，可多选） | 操作后释放的结果原文 | 来源文件、页码或段落 | 对应附件 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

- 不因学生选择器材就显示正确部位。器材、部位与体位由学生选择，后台按本表核验后释放结果。
- 体位来自教师明确要求；未确认时留待核实，不给每例套一套新编规则。婴幼儿站立限制继续沿用既有年龄规则。
- 未做、原资料未提供、不适用、待回报、系统读取失败分别记录，禁止补默认正常值。
- 同一器材与部位只登记一次；两种体位均适用时写在同一行。不同体位若有不同操作或结果，应先核实并拆成明确项目，不将两份结果混写。

### 检查申请、时点与附件

| 可申请的明确名称 | 同义名称/原报告标题 | 院外或入院后等时点 | 原始结果及单位 | 最早回报阶段/延迟说明 | 附件来源与对应项目 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

原资料是成组报告时保留明确来源标题，不猜拆单项，不把数值或结论当项目名称。图片必须对应实际检查或操作，不放在页面底部整包展示。

### 病历书写资料

服务端标准病历按主诉、现病史、既往史、个人史、家族史、体格检查、辅助检查、初步诊断、鉴别诊断、诊疗计划整理。已有内容保持原文与来源定位；缺失项标明。学生端采用目录、逐段编辑和思考提示，依据本轮已获得的信息自行书写，不预填标准答案。段落完成度是书写提示，不自动视为临床能力得分。

### 每入口验收记录

| 入口 | 来源病例及版本 | 年龄/性别/主诉 | 自主定位及错误体位不放结果 | 检查与图片对应 | 病历草稿恢复/提交 | 接诊到报告及刷新 | 账号/设备 | 状态与未验项 |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |

结构校验、离线引擎、数据库导入回读、真实账号页面、手机/语音和医学教学审核分别记状态。工程模板通过不代表所有病例医学验收或全流程已通过。
