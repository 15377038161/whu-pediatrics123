# Coder服务器接收与运行指令

本文件按用户最新分工更新。内容和代码由Codex完成，旧版“让Coder继续实现、合并设计或自行发布”的指令已撤销。Coder只作为服务器，不补写业务代码。

1. 只读取Codex给定的GitHub分支及完整提交SHA。先返回当前HEAD、分支和工作区状态；有额外修改时保留并回报，不reset、clean或覆盖。
2. fetch指定分支，确认目标SHA属于该分支。以快进方式接收；不能快进则停止代码合并并把差异交回Codex，不自行解决冲突。
3. 复用当前Node、pnpm、环境变量和构建约定。凭据不进聊天、命令参数、Git或日志，不使用聊天中出现过的令牌。
4. 按Codex指令安装依赖、类型检查、构建并启动预览，返回实际命令、退出码、日志位置、监听端口和提交SHA。不要以构建通过代替浏览器、真实登录或医学验收。
5. 私有病例包与媒体只按Codex给定的清单安装到受控目录，不上传GitHub或public，不修改源版本或历史会话绑定。不自行生成补充病例或重算历史报告。
6. 只更新预览运行，不点击发布或变更线上病例。对象清理另按明确的对象清单和操作指令执行，不扩大删除范围。
7. 运行故障只提供可核对的错误和环境参数，修复代码交回Codex。接收完成后保持服务器职责，等待下一条具体运行指令。
