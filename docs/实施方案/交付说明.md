# 珞珈儿科智训｜智能体实施方案交付说明

## 交付结论

本方案已将项目统一定义为一个“儿科临床教学智能体”，而不是问诊、查体、沟通、OSCE 等页面或功能的简单拼接。模拟病例训练、专项能力训练、OSCE 模拟考站是同一主智能体的三种运行策略，共用同一病例状态机、专业工具协议、事件证据账本、知识资源版本和教师治理流程。

## 文件清单

- `珞珈儿科智训_智能体实施详细计划与技术方案.docx`：正式汇报与研发实施主文档，共 23 页。
- `珞珈儿科智训_智能体实施详细计划与技术方案.pdf`：固定版式展示稿，共 23 页。
- `珞珈儿科智训_智能体实施详细计划与技术方案.md`：便于团队协作和后续版本维护的文本稿。
- `assets/`：总体架构、智能体闭环、统一病例状态机、部署架构和 16 周路线图等原始示意图。

## 方案覆盖范围

1. 单一智能体定位、角色、边界及不采用的架构做法。
2. 主智能体、确定性专业工具、知识资源、数据与证据账本的完整分层。
3. 同一病例从问诊、查体、辅助检查、判断、处置、沟通到 OSCE 评分和专项补练的纵向闭环。
4. Web、手机和教师端页面与智能体能力、工具调用的逐项映射。
5. API、数据字段、事件类型、推荐技术栈和部署边界。
6. 医学审核、版本锁定、隐私授权、安全拦截和模型故障降级。
7. 16 周实施任务、阶段交付物、门禁、测试、验收指标和完成定义。
8. 老师需提供材料的用途、最低要求和提交时间。
9. 12—15 分钟比赛演示链、断网与模型异常预案。
