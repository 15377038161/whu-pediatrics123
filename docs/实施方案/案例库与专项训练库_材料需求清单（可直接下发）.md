# 《珞珈儿科智训》案例库与专项训练库 材料需求清单

**说明**：本文档列出平台智能体运行所需的医学材料。老师需提供医学事实（交现成的脱敏病历、病例讨论记录、教学查房资料、课件均可）。

***

| 呼吸系统   | 肺炎·细菌性                | <br />                                                           |
| 呼吸系统   | 喘息性疾病（毛细支气管炎/哮喘发作任选）  | <br />                                                           |

| 感染/传染病 | 急性传染病（麻疹/水痘/手足口病任选其一） | 需写明隔离与上报要求                                                       |
| 新生儿科   | 新生儿黄疸                 | 注意日龄分层判断                                                         |

## 二、每个病例要准备什么：按"患儿就诊流程"连贯准备

请把这个病例想象成**今天走进你诊室的一个患儿**，按下面这条就诊流程把材料连贯地写下来——智能体就是按这个流程和学生互动的，每一站用到什么材料、哪里要附音频图片，一张表说清楚：

| 流程环节            | 智能体在这里做什么                  | 老师要写的材料                                                                                              | 这一站可能附的素材                                                       |
| --------------- | -------------------------- | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| **① 患儿走进诊室**    | 开场：给出患儿形象、家长第一句话、情绪和生命体征   | 病名；患儿性别、年龄（精确到月龄更佳）；接诊时第一眼看到什么（精神、呼吸、体位）；家长开场白（口语）；家长情绪（紧张/平静/低落/抗拒/焦虑/中立六选一）；初始体温、心率、呼吸、血氧（按年龄给合理值） | **咳嗽声/喘息声音频**——如果这个病有特征性咳声或呼吸音，附一段，让学生"未见其人先闻其声"                |
| **② 学生开始问诊**    | 学生提问，智能体以患儿或家长口吻回答；没问到的不透露 | 问诊要点清单：每条写"要点名称＋标准回答＋谁来回答（患儿/家长/都可能）＋重要程度（1～10 分，危险信号给高分）"；条目数按病例需要，够推出诊断即可                          | 一般无                                                             |
| **③ 学生做体格检查**   | 学生选器材和部位，智能体即时返回查体所见       | 查体项目清单：每条写"查哪个部位＋用什么器材（听诊器/压舌板/体温计/血氧仪/血压计等）＋具体结果＋是否关键项"；条目数按病例需要                                    | **听诊音频**（如诊断依赖肺部啰音/心音，附录音或录音说明）；**症状图片＋位置**（皮疹、口腔黏膜斑等：照片＋长在哪里；） |
| **④ 学生开检查单**    | 智能体返回检查结果，并评价该不该开这项检查      | 检查项目清单：每条写"检查名称＋为什么选＋标准结果与解读＋该不该选（不该选的写一句理由）"；建议顺手带 1～2 项不该做的对照项，数量不作硬性要求                            | **影像图片**（胸片、CT、心电图等，脱敏后附）；化验单图片可选                               |
| **⑤ 学生下诊断、开处置** | 智能体对照标准答案评价                | 标准诊断＋至少 2 项鉴别诊断及支持/不支持依据；标准处置方案（一般处理＋用药/非药物处理＋隔离、上报、转诊要求）；入院后进一步检查结果（供⑦病历书写与复诊判断用）                   | 一般无                                                             |
| **⑥ 学生向家长交代病情** | 智能体扮演家长回应                  | 沟通话题 1～2 个：每个写"场景背景＋沟通任务＋家长可能的 3 条质疑"（例："为什么上次骨穿没成功？""必须保证这次成功""要主任亲自做"）                             | 一般无                                                             |
| **⑦ 学生书写病历**    | 学生按本例写一份首次病程记录，智能体对照标准记录反馈 | 本例标准首次病程记录（可由⑤的诊断与处置整理成稿，老师提供）；本例书写中最容易漏写、写错的点各列 1～2 条                                               | 一般无                                                             |

**关于素材的两句话**：

- 音频、图片、影像**只附这个病例诊断所依赖的那些**——靠听诊音诊断的附听诊音频，靠皮疹诊断的附照片和位置，靠影像诊断的附片子；不需要素材的病例不用硬凑；
- 素材的授权要求：自有授权/可教学使用/无授权。

## 三、我们必须要的几样东西

其余细节都可以商量和补做，但下面几条直接决定智能体能不能跑起来：

1. **查体结果必须具体、可仿真**。学生做体格检查时，智能体要即时给出"查了会看到什么"。如果只写"肺部有异常"这类含糊描述，学生无法定位病变和鉴别诊断，查体训练就失去意义。请给到能直接读出来的具体所见（部位、性质、范围，如"右下肺可闻及固定中湿啰音"）。
2. **问诊回答要分患儿/家长两个版本的事实依据**。患儿说儿语、家长讲细节，智能体据此切换口吻；老师只需给医学内容，话术由我们拟。
3. **病例内部自洽**：症状、体征、化验数值、影像表现、最终诊断互相印证，符合指南诊断标准；数值符合该年龄生理范围。
4. **全部材料脱敏**：无真实姓名、住院号、检查报告编号、二维码、可识别人脸。

## 四、专项训练库需要的材料（4 个已有专项＋1 个新增病历书写）

平台的专项训练不是独立的病例库，而是**案例库病例＋一个训练重点**：学生从专项入口进入，沿完整病例动线训练，智能体按重点侧重评价。所以专项训练**不需要单独准备病例**，只需在病例材料上补充以下内容：

| 专项                    | 平台现状         | 老师要补的材料                                                                 |
| --------------------- | ------------ | ----------------------------------------------------------------------- |
| 儿科病史采集（history）       | 已有           | 每个病例标出 2～3 条问诊要点作为本专项重点（如危险信号必须问到）                                      |
| 肺部规范查体（exam）          | 已有           | 每个病例标出 1～2 条查体项作为本专项重点（准备动作、器材与部位匹配）                                    |
| 感染与危重识别（safety）       | 已有           | 每个病例指出决定处置优先级的生命体征与所见（如血氧、呼吸频率、局灶体征）                                    |
| 家长焦虑沟通（communication） | 已有           | 直接用各病例⑥环节的沟通话题；合计不足 6 个时补几个（背景＋任务＋3 条家长质疑）                              |
| 病历书写（charting）        | **平台将新增此入口** | 每例一份标准首次病程记录（老师按⑤的诊断与处置整理提供）＋本例最容易漏写、写错的点各 1～2 条；记录格式直接用国家考核方案样张，无需老师排版 |

另有两份公共规范请老师尽量提供现成材料（教学讲义、查体规范、培训资料均可）：**儿科问诊通用模板**（出生史/喂养史/生长发育/预防接种/传染病接触史 5 套问题序列）、**儿科大查体标准流程＋年龄分层生命体征正常值**。医学内容平台不宜代写；老师确提供不了的，我们再想办法解决。

***

## 五、提交格式与批次

**格式**：一个病例一个文件夹，命名 `大类_小类_病种`（如 `呼吸系统_肺炎_支原体肺炎`）；文件夹内按就诊流程环节①～⑦组织即可，不要求按我们的字段格式整理，现有材料散装放入也行，结构化由我们完成；素材放在文件夹内并标注所属环节和授权情况。
