# 2026-10-13 接口与运行变更

## B：接诊与训练闭环

- `POST /api/sessions` 保留mode/caseId/focus；新增random、excludeCaseId、allowRepeat、clientRequestId。random只允许guided/immersive，必须UUID请求标识，与指定caseId互斥。重试沿用同一标识、相同参数；同标识改参数返回409。
- 请求标识与本人身份派生会话主键，利用既有主键唯一约束抵御跨进程重复创建，无新增迁移。未指定标识的旧调用仍有效。
- 随机池只读取当前服务端可读的完整事实与可信主诉，过滤下架、缺资料和待审核演示；按来源合并别名。资料仅在数据库而本机无法同步读取的病例暂不进随机池，不做批量网络召回和事实兜底。
- 当前病例及同源别名排除。只有当前来源时409 ONLY_CURRENT_CASE；用户明确点击重练后allowRepeat=true。零例返回409 NO_ELIGIBLE_CASE。旧会话不被完成或删除。
- `GET /api/cases` 返回从受控事实提取的主诉，不含完整正文和诊断；无法核验时标题为待补充接诊信息。上下架查询失败不再静默全量放行。
- active学生会话公开caseOptions添加complaint；tests仍剥离；会话绑定版本用于读取主诉，防止版本漂移。
- `ORDER_TEST`仍走文本申请。精确名称优先，复查后缀有边界；CT/CTA、胸部/胸腹部、合并项目不可混同。含糊申请提示澄清，未识别不代表医学错误，已有结果不编造。
- 报告新增studentDecision（生成时的最终提交副本），保存初步诊断与依据。历史报告缺字段显示历史未保存，不重写。
- 原患者媒体脱敏门控保持默认关闭，学生文档访问继续拒绝；训练完成不自动解锁原始影像。复盘仍以报告中受控文本为入口。

本轮B单测：接诊零/一/多例、同源排除、并发创建与冲突、报告快照、匹配歧义/跨方式、公开投影、媒体权限。本地媒体测试旧样本选到了缺来源条目，改用有来源病例；缓存命中无需重新配置知识库凭据，网络召回仍必须配置。

## 验收身份与环境

真实平台凭据不在CLI参数或日志中。现有预览Cookie读取仅用于合成接口测试，不恢复已删除登录入口。生产持久化/真实多身份验收仍需现有测试账号的受控凭据，不能用合成测试声称通过。

## C：检查方法与姿势

EXAM_ACTION新增可选posture（standing/supine）；工作台新操作显式传入姿势，腹部新操作需仰卧，否则不解锁证据。历史未带姿势的事件仍可读取与兼容调用，不能据此声称过去做过仰卧检查。session.examPosture保存最新操作姿势。

源病例按原文片段拆分腹部视、触、叩、听与神经反射，不再把整段查体归到触诊或用整份原文兜底。未匹配到明确方法的内容暂不提供结果，需教师补充规则。示例病例没有相应记录的组合提示资料未提供/操作不匹配，不补正常事实。仰卧图为仓库原创教学示意，不是患者照片或儿童解剖模型。
