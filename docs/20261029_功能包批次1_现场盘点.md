## 5. 本功能包工程纪律（沿既有范式）

- 迁移只新增带时间戳前缀文件，不改历史迁移；RLS 不放宽；security definer RPC 显式 `revoke all ... from public, anon` + `grant execute ... to authenticated`。
- 权限裁剪走服务端投影（projectSessionForRole 模式），禁止 CSS 隐藏充当权限。
- 幂等沿用 client_event_id / request_id 唯一约束范式（clinical_operations、班级动作已实践）。
- 学生答案边界：报告完成后才释放病种名（REPORT_ANSWER_BOUNDARY）；病历书写模块的标准病历整篇不进学生响应/页面源码。
- 稳定 caseId+版本关联：training_sessions.case_id+case_version 已落库，新模块沿用。
