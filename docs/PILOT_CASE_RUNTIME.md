# 单例运行资料接入

正式新会话优先读取case_publication.active_version；无显式版本的入口在单例试点期保留现有选择链。会话创建后保持原有sourceSnapshotVersion，历史会话不重新选版。未能读取显式版本时报可重试错误。

受控病例包的fileId、SHA256和内容版本仅保存在服务端模块controlled-case-bundle.ts。服务器从既有官方StorageClient读取，验证整包、manifest、逐文件指纹、病例Schema及完整内容版本后，在服务端登记精确来源版本；不执行包内SQL、不写临时运行目录、不把原文传入浏览器。读取采用现有本地受控病例事实的引擎路径，API继续执行身份、会话归属及学生响应投影，图片继续按实际操作事件释放。

当前数据库函数更新被平台审计拒绝，没有执行。此路径使用现有服务端完整来源能力，不修改函数ACL、RLS或账号。数据库中仍需由真实教师身份导入配对事实/答案及binding_config，便于持久记录和一致性回查。

已登记历史包不能在仍有会话引用时删除。服务重启后按来源和精确版本重新从持久对象加载；禁止依赖进程缓存或output目录作为唯一资料。新增包必须完成来源核对、指纹登记和专项测试，不能接收客户端任意fileId。
