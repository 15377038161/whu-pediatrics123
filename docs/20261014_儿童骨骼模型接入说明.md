# 儿童骨骼模型接入说明

## 来源与筛选

用户明确要求儿童骨骼，不接受成人模型替代。GitHub 检索找到 React Three Fiber 项目 [3D-Human-Skeleton](https://github.com/vincentgg6886/3D-Human-Skeleton)，参考提交 `2ff63803e768a2b67b283944b3a317c574fd5d88`，其成人骨骼资产不纳入本项目。参考其 Three.js 交互路线，复用本项目现有 React Three Fiber/Drei 依赖进行最小接入，没有复制整套成人病例、病理模拟或全站架构。

最终资产来自 [PIPER Child](https://www.piper-project.org/child) 官方开放研究项目：[源码](https://gitlab.com/piper-project.org/child)，固定提交 `6aeee0cec84570e1455f797ac49e4721eb89fdee`，`PIPER_ChildModel_6YO` 原始年龄字段为6。该模型面向生物力学研究，并非逐块完整儿童解剖教学图谱。我们仅提取其骨骼表面，没有进行年龄变形、比例缩放冒充不同年龄、患者建模或碰撞模拟。

另一个名为 Child Skeleton 的 Sketchfab 候选自述为首次雕刻作品，没有医学审核和年龄证据，因此未采用。现有页面不加载 Sketchfab iframe、成人资产或第三方热链。

## 转换与范围

`scripts/convert-piper-child.py` 从上游 part 名称中的 `_BO_` 选择骨骼材料，读取 `mesh_PIPER_Body.k`、`main_Head_Skull.k`、`main_Neck.k` 的节点与单元。壳单元三角化；无壳表面的实体提取外边界；转换毫米/Z-up到米/Y-up。源模型中的骨骺、骨干等网格仍分开，部分前臂、手足等结构原本合并。原始姿势保持，无成人网格和人工补骨。

产物：`public/models/anatomy/piper-child-6yo.glb`（约4.6MB），130个网格部件、217482个三角形；`manifest.json` 记录年龄、部件原名、区域、三角数及GLB SHA256。130不是人体骨头计数，不宣传“完整206骨”。部件标签对应源网格，骨骺等不作为新的独立骨头。骨缝、软骨、肌肉等未一并提取，不能用于骨龄判读、患者诊断或生理运动模拟。教学命名及适用范围还需要儿科教师审核。

复现：

```powershell
git clone https://gitlab.com/piper-project.org/child.git outputs/piper-child
git -C outputs/piper-child checkout 6aeee0cec84570e1455f797ac49e4721eb89fdee
python scripts/convert-piper-child.py outputs/piper-child
```

转换需要 Python + NumPy，仅用于离线资产制作，生产运行不新增 Python 依赖。不执行外部仓库脚本。

## 界面与架构

原 `anatomy-lab.tsx` 的二维色块和对应CSS已移除。现使用 `anatomy-scene.tsx` 动态加载 Canvas，浏览器加载本地GLB；旋转、平移、双指缩放使用 OrbitControls。支持正/背/侧视角、重置、八区域显示、单部件高亮及隔离、0–100%结构分离。结构分离只是显示位移，不改变骨骼几何，不表示医学上的关节活动。模型失败显式报错并允许重试，不生成虚假占位骨骼。

按需渲染，DPR上限1.5，无新运行库（仅补显式 `@types/three` 开发依赖）。模型缓存共享几何，交互副本材质退出时释放。身份门控和API未变。

## 验证边界

`tests/anatomy-model.test.ts` 核验GLB格式、清单指纹、年龄、八区域及头颈材料，避免遗漏分文件结构。`scripts/verify-anatomy-ui.py` 在本机合成学生身份下实际加载GLB/WebGL，验证390/768/1440宽度、区域/高亮/隔离/分离/重置、无整页溢出及模型404错误提示；包括画面像素变化和直接点击三维骨骼的射线选中。开发模式及生产构建模式（`--base http://127.0.0.1:8772`）均通过。`pnpm validate` 237通过、4项真实AI测试跳过、0失败；`pnpm build`通过。旧 `verify-browser-entries-ui.mjs` 中二维DOM断言已替换为当前模型交互，完成语法校验，本轮没有真实账号条件来复跑该脚本其他模块。这不是线上鉴权或医学适用性验收。正式部署需拉取新提交重新构建，并在平台浏览器验证模型请求200与WebGL支持。
