# 辅助检查：原始结果提取与教学补全

学生继续输入常用检查名称，不需要猜“外院检查记录”等资料分组标题。服务端先走既有名称/别名匹配；裸 CT、MRI 或超声只有一个对应项目时使用该项目，存在多个部位时要求明确部位，不跨检查方式映射。

未匹配项目通过项目既有 `invokeCozeAI` 调用平台模型，一批申请只调用一次。先从绑定版本的可回报报告提取单项；提取结果必须逐字对应已有原文，保留日期、单位与来源定位。没有原始结果时，依据病例资料、已知指标和此前报告补全教学结果。模型不能修改原始数值、猜造附件、输出未申请的全部资料或诊断标准答案；没有完整病例背景时不生成。延迟回报规则继续由服务端执行。

训练入口统一说明“教学仿真”，各检查保持正常报告样式，不按来源逐项打标签提示学生。`SessionState.supplementalTests` 在后台留存 source/generated、来源引用、模型、创建时间和绑定版本；学生投影不包含这份审计字段，学生只收到本次已释放结果事件。教师仍可查看审计信息。

补全结果只保存于当前会话的既有 `training_sessions.state`，不导入病例快照、不改版本、不修改真实原件。再次申请相同名称或已识别别名时复用已保存结果；页面刷新从会话状态恢复，不重新生成。来源快照版本变化时不能复用旧版结果。新增结果使用独立 `SUPPLEMENT_TEST_` 证据码，不冒充原始 `SOURCE_TEST_` 或已审核医学评分项。

模型默认复用当前角色模型，优先级为 `COZE_AI_TEST_MODEL` → `COZE_AI_ROLE_MODEL` → `doubao-seed-1-8-251228`。这是可选模型名配置，不增加浏览器端密钥或新供应商。平台调用失败、响应无效或引用核验失败，返回可重试的未取得报告状态，不伪造正常结果。一次最多补全 12 项，单项最长 160 字。

无需数据库迁移，不需要重导入或激活现有病例包。后续病例沿用相同流程与填写模板；AI 不能替代教师对教学合理性和参考区间的审核。

回归重点：常用名称和合并报告单项、原文引用防篡改、正常与异常结果、模糊影像部位、重复申请/刷新一致、模型失败不解锁结果、延迟报告守卫、学生投影与教师审计、原始包版本不变。
