# 辅助检查：原始结果摘录（不生成模拟结果）

学生继续输入常用检查名称，不需要猜“外院检查记录”等资料分组标题。服务端先走既有名称/别名匹配；裸 CT、MRI 或超声只有一个对应项目时使用该项目，存在多个部位时要求明确部位，不跨检查方式映射。

未匹配项目通过项目既有 `invokeCozeAI` 调用平台模型，一批申请只调用一次，模型只做一件事：从绑定版本的可回报报告中逐字摘录申请对应的单项，保留日期、单位与来源定位。**原始资料没有对应结果时，不生成、不编造、不补全任何结果数值**——2026-11-05 按老师执医三站要求关闭了原「教学补全」通道：无结果的检查学生只能选择做/不做，平台明确回复「本病例原始资料未提供该项结果」，并把申请作为操作记录留痕；报告端按 `requested_unavailable` 记为「已申请，但尚无已取得的结果证据」，不认定为漏做或解释错误。模型不能修改原始数值、猜造附件、输出未申请的全部资料或诊断标准答案；没有完整病例背景时不调用。延迟回报规则继续由服务端执行。

`SessionState.supplementalTests` 只保存原文摘录（origin=source）、来源引用、模型、创建时间和绑定版本；学生投影不包含这份审计字段，学生只收到本次已释放结果事件，教师仍可查看审计信息。2026-11-05 之前落库的 origin=generated 历史记录不再被复用（`findSupplementalTest` 只认 source），旧会话再次申请同一项目会得到「资料未提供」，不会重新下发此前的合成报告。

摘录结果只保存于当前会话的既有 `training_sessions.state`，不导入病例快照、不改版本、不修改真实原件。再次申请相同名称或已识别别名时复用已保存摘录；页面刷新从会话状态恢复，不重新调用模型。来源快照版本变化时不能复用旧版结果。新增摘录使用独立 `SUPPLEMENT_TEST_` 证据码，不冒充原始 `SOURCE_TEST_` 或已审核医学评分项。

模型默认复用当前角色模型，优先级为 `COZE_AI_TEST_MODEL` → `COZE_AI_ROLE_MODEL` → `doubao-seed-1-8-251228`。这是可选模型名配置，不增加浏览器端密钥或新供应商。平台调用失败、响应无效或引用核验失败，一律回落「资料未提供」，不伪造正常结果。一次最多处理 12 项申请，单项最长 160 字。

无需数据库迁移，不需要重导入或激活现有病例包。后续病例沿用相同流程与填写模板；AI 只做原文摘录，不能替代教师对教学合理性和参考区间的审核。

回归重点：常用名称和合并报告单项、原文引用防篡改、origin=generated 一律拒绝、无结果申请只记录做/不做且不解锁证据、模糊影像部位、重复申请/刷新一致、模型失败不解锁结果、延迟报告守卫、学生投影与教师审计、原始包版本不变。
