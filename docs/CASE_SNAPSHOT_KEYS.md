## 问题与行为

关联病例的会话保存首页入口 `state.caseId`，事实与答案快照保存在来源病例 ID 下。旧应用向会话 RPC 传来源 ID，数据库却用该参数严格核对入口：14 个关联入口会被拒绝；只改应用传入口 ID，又找不到来源快照。

五个会话 RPC（恢复事实、检查目录、持久化下单、逐项结果、教师对照）现在统一接收入口 ID。数据库仍先核本人、绑定版本、入口严格相等，再按固定关联表选择来源快照。下单的项目范围/完成态拒绝、结果的已下单校验、教师对照限制均保留。来源版本查询与教师受 RLS 保护的来源直读继续使用来源 ID。

不重写已有会话、病例事实、绑定版本、检查 ID 或下单记录；未知入口不猜来源；缺指定来源版本仍返回空。亚型只修既有映射的读取契约，不据此认定其临床内容等同来源或已审核。
