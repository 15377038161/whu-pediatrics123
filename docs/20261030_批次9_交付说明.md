## 三、功能现状摘要

- **认证权限**：超星 OAuth + 邮箱密码；`x-sandbox-authorization` 头鉴权链路；身份冲突 403；全部受保护 API 匿名 401。
- **病例库**：67 入口（53 独立来源 + 14 关联），上下架可恢复停用，教师索引三要素视图。
- **训练闭环**：问诊/查体/检查/诊断/处置/沟通六阶段，确定性引擎 + Coze AI 降级契约（模型失败回退确定性应答，问诊不中断）。
- **OSCE**：阶段顺序限制、无提示无重试、计时、防回退。
- **题库**：43 题单题速练（判分/复盘/锁定）+ AI 题集（生成草稿→审核→发布冻结快照）。
- **病历书写（批次6）**：学生书写/草稿/提交，教师查看，AI 流式审阅。
- **技能学习（批次7）**：8 项 OSCE 技能目录，观看达 90% 服务端标记完成；完成度仅展示，不入临床评分。
- **现场考核（批次8）**：40 项统一评分项三档打分（2/1/0，未观察不计分），汇总 0-100；发布制 + 撤回 + 补考留痕；成绩独立于 OSCE 参考评分与训练报告成绩，不互换算。
- **学情教师台**：学生档案三级进度、报告复核、提醒区+学期汇总+CSV 导出、使用统计（有效活跃口径、脱敏导出、非正式成绩标识）。
- **班级管理**：创建/名单导入/入班审核/跨班边界。
- **学习资源**：教师上传/发布/可见性/签名播放，学生观看进度。
- **3D 解剖实验室**：8 部件联动、爆炸滑杆、移动端缩放。
- **语音链**：服务端 capabilities/ASR/TTS 三路由（本人归属校验）；真实设备链路属用户侧验收。
