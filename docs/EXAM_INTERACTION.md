# 人物图片点选查体

业务代码和内容由 Codex 维护。Coder 只拉取指定 GitHub 提交、安装依赖、构建、运行和返回日志，不自行补写或改造业务功能。当前改造用于本地与服务器预览，不代表线上发布或正式成绩切换。

学生在一个人物画布内完成检查：先拿器材或点击大部位，展开的小部位按钮与人物共处同一画布；头面、心前区等密集位置可在原画布放大，再返回全身。取消旧的「全身人物＋另一张局部图＋独立结果栏」三栏结构。病例记录通过顶栏按钮打开抽屉，查体首屏不再常驻第二栏。

默认显示腋下电子体温计，额温枪和耳温计收进「其他测温方式」。这三种方法仍分别绑定腋窝、额部和耳部，图片与规则独立。器材栏不按病例阳性结果筛选，也不提前标示正确答案。

相同器材、部位、侧别、观察面及实际体位的已完成检查静默忽略重复点击；不再弹窗、播报、写入第二条记录或重复计分。前端提前拦截，服务端按结构化操作再次校验，刷新后仍生效。错误配对在相同条件下也不反复提示；完成准备、纠正配对或改变必要条件后可重新检查。既往结果从病例记录主动查看。历史粗部位记录不冒充新小部位操作。

## 代码与定位

- `src/components/clinical-exam.tsx`：单一人物画布、器材、持有器材的指针效果、检查触发和当前结果。
- `src/domain/exam-photo-map.ts`：按素材标识和站立或仰卧体位分别登记照片坐标。百分比相对于完整照片，局部放大按同一裁剪矩形换算。未知素材不套用另一人的定位。
- `src/domain/exam-canvas.ts`：把既有局部坐标换算到全身图，放大沿用同一裁剪；背部使用共用示教模板。
- `src/domain/exam-action-identity.ts`：结构化操作身份和重复检查判定，历史无定位信息不推断。
- `src/domain/exam-anatomy.ts`：部位目录和器材适用性。图片区和文字入口共用同一部位编号。
- `src/lib/agent-engine.ts`：服务端检查器材、部位、侧别、体位与准备条件；错误搭配不解锁体征或媒体。旧的 `thermometer` 编号仅解释历史客户端，新界面使用三种明确的体温计。
- `src/components/exam-region-panel.tsx`：逐项显示已释放的客观所见、操作过程和配合反应，通用正常参考单独折叠。

照片仅用于互动定位，不表示患者本人或病例体征。正面复用已校准的年龄与性别模板，背面使用明确标记的通用医学示教模板；全身与测量保留同一人物，通过小部位按钮选择功能性检查。头颅、前囟、足底和会阴若照片无法可靠呈现，只提供明确文字入口，不在头发、鞋面或衣物上伪造可见结构。

界面持续标记患者左右。选择背面不等于已翻身；坐位、侧卧、俯卧仍用现有照片作为定位参考，并明示图示未随体位变化。实际操作是否合法由服务端体位规则决定。

背部模板由内置 imagegen 生成，文件为 `public/media/clinical/exam-back-teaching-v1.png`。提示词要求：通用儿童比例医学示教背面、无病理、无身份文字或标注、髋部遮盖；不可当作原患者影像或细微影像考题。

## 结果与版本

检查调用既有 `EXAM_ACTION`，不新增客户端判分或平行引擎。正确组合展示该会话固定版本的结果；原记录、教学模拟、参考说明保留各自标识。正常记录描述正常所见，异常记录展示客观异常，不自动告诉学生诊断。无可靠患者数值的项目不补造测量值。换器材、部位、侧别或体位后清除当前结果卡，既往已获得信息仍在病例记录中。

OSCE闭卷站在服务端不释放通用操作要领及程序性配合提示，界面也不显示正常参考折叠区。原记录与固定模拟的客观所见继续释放；只有参考说明、缺少独立患者记录的项目仅说明资料局限，不把通用正常文字作为患者结论。历史会话和已保存报告不重算。

眼部来源提取已排除因“睁眼”词语误入的 Glasgow 评分，独立瞳孔与对光反射记录保留。重新制作教学包时产生新教学版本，不就地修改旧版本或重算历史报告。只有源版本与教学包绑定相符的新会话才能使用新版；代码上线本身不能证明新版病例资料已启用。

通用新增图片发布为 WebP，保持稳定、无病名的素材名称；原始 PNG 保存在本地备份及历史版本。病例检查图片继续走原有受控媒体接口，不能放进通用公开素材目录。

## 本地验收

真实应用开发服务与合成身份验收服务分开。以下两个终端只用于本机界面验证，现有登录代码不改动：

```powershell
$env:NEXT_DIST_DIR='.next-exam'
pnpm exec next dev -H 127.0.0.1 -p 8876
```

```powershell
$env:ENABLE_AI_FIXTURE='true'
pnpm exec tsx scripts/training/ui-fixture-server.ts
```

浏览器打开 `http://127.0.0.1:8875/student/training`。8875 仅绑定回环地址，使用既有引擎与投影处理合成学生会话，并代理8876的真实页面；不写线上数据库，不可当作真实登录或持久化通过。代理未转发开发热更新连接，改代码后刷新页面。

服务器按项目现有 pnpm、Next.js、TypeScript 和构建脚本运行，默认开发端口使用 `DEPLOY_RUN_PORT`，当前服务器为5173。新增路由须重新构建。不得删除正在服务的 `.next`，不得将合成验收适配器作为外网服务发布。

## 逐例内容矩阵

`scripts/training/build-exam-matrix.ts <受控runtime目录> <outputs下私有目录>` 从实际版本化病例包导出67例索引、重点查体及可接受操作、11390条部位器材结果行、170个通用正常模板、61个部位去重总表。先验证包指纹，再导出中文列名 CSV 与完整 JSON。教师专用矩阵含答案，禁止加入 Git、公有目录或学生会话接口。

原记录、固定教学模拟、仅参考说明分别计数；参考说明不是已补齐的患者正常所见。缺乏独立测量值、分级或可能与病情冲突的局部结果仍需内容核对，不以“与最终诊断无关”直接判正常。矩阵覆盖不等于逐例医学审定或真实师生验收通过。
