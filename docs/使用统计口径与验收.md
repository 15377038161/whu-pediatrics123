# 教师学生使用统计——口径说明与验收记录

实施时间：2026-10-11
性质：最小实现（仅授权范围内：复用内置数据库与既有教师白名单，不推送发布，不新增第三方埋点）

## 一、数据模型（supabase/migrations/20261011100000_session_engagement_events.sql）

| 对象 | 说明 |
|---|---|
| `student_engagement_events` | 学生学习事件表：user_id / session_id(uuid, 可空) / event_type / occurred_at(服务端时间) / client_event_id(幂等键) / session_tab_id(多标签区分) / detail(脱敏元数据)。唯一约束 (user_id, client_event_id) 保证幂等 |
| `student_active_intervals` | 有效活跃区间表（服务端派生）：user_id / tab_id / started_at / ended_at / duration_seconds。无 INSERT/UPDATE 策略，只能由 RPC 派生 |
| `engagement_record_event()` | 受控事件上报 RPC（SECURITY DEFINER）：归属强制（auth.uid()）、会话归属校验（不能挂他人会话）、服务端时间、幂等去重、派生/续期活跃区间 |
| `teacher_stats_per_student / overall / daily_trend / case_distribution()` | 教师统计 RPC（SECURITY DEFINER，内部 `app_is_teacher()` 白名单 fail-closed）：明细 + 汇总 + 日活趋势 + 病例/模式分布 |

事件类型：`session_start` / `session_end` / `page_enter` / `page_leave` / `visibility_active` / `visibility_idle` / `heartbeat`。

## 二、有效时长口径

- 只统计**页面可见且活跃**的时间：`visibility_active` / `page_enter` / `session_start` / `heartbeat` 开启 10 秒最小活跃区间，同标签页 5 秒内的后续活跃事件归并续期；
- **隐藏页 / 切后台**（`visibility_idle`）、**离开页面**（`page_leave`）不驱动区间，区间自然截止；
- **多标签去重**：区间按 `tab_id`（sessionStorage 标签页 ID）独立计算，同浏览器多标签不重复累计同一时间片；
- **挂机不计入**：无心跳（30 秒间隔）则区间不续期；
- **不信任客户端时钟**：`occurred_at` 一律为数据库 `now()`，客户端时间仅存 detail 供排障；
- 心跳间隔 30 秒 + 归并窗口 5 秒：正常使用下区间连续，网络抖动 <5 秒不丢失，挂机 >35 秒不累计。

## 三、统计范围与测试数据分离

- 统计一律 join `profiles` 且 `app_role='student'`：RLS 探针（rls-probe-*）、联调账号（教师角色/无 profile）、新注册验证身份（usage-probe-*，display_name 标注统计探针）不进入教师统计；
- 预览演示身份（provider=preview）走进程内存不入库，事件上报接口直接返回不入库，与真实数据天然分离；
- 练习成绩（training_reports.total_score）输出处均带"非正式成绩"标识（scoreBasis: practice-only）。

## 四、API

| 接口 | 方法 | 鉴权 | 说明 |
|---|---|---|---|
| `/api/engagement` | POST | student | 事件上报：服务端身份+时间+幂等；返回 `{accepted, persisted}`（重复事件 accepted=false） |
| `/api/teacher/usage-stats` | GET | teacher | 统计查询：`from/to`（日期）、`userId`、`caseId` 筛选；`format=csv` 输出脱敏汇总（姓名/学号脱敏，无 user_id 明文、无患者数据） |

权限模型：学生调教师统计 403；未登录 401；学生直调统计 RPC 被拒（FORBIDDEN）；事件挂他人会话 403；RLS 行级隔离（学生只见自己的事件）。教师判定复用既有 `app_is_teacher()` 白名单（未修改白名单，未修改任何既有 RLS 策略）。

## 五、前端

- 学生端布局挂载埋点（`StudentEngagement`）：进入/离开/前后台切换/心跳；
- 训练页上报 `session_start`/`session_end`（挂载/卸载）；
- 教师端新页面 `/teacher/usage-stats`（教师导航"使用统计"）：汇总卡片、学生明细表、日活趋势、病例/模式分布、日期/学生/病例筛选、脱敏 CSV 导出（fetch+blob 下载）；空数据诚实展示"暂无数据"。

## 九、专项复核与修复（2026-10-13，迁移 20261013100000_teacher_usage_stats_review.sql）

针对 8 项统计口径与安全缺口的真实 DB 复核结论与修复：

### 复核发现（真实 DB 取证）

| # | 缺口 | 取证结论 |
|---|---|---|
| ① | 日期时区 | DB TimeZone=UTC，`p_from_date::timestamptz` 按 UTC 0 点截断：实测 31 个 UTC 16:00 后（北京次日 0–8 点）的会话被归属错日；`from>to` 无校验；非法日期（2026-02-31）直接 500 |
| ① | 跨日截断 | activeHours 按区间 `started_at` 全量归属，未按筛选边界裁剪分摊 |
| ② | caseId 筛选 | per_student/overall 的 activeHours 子查询均无 case 条件，caseId 筛选对时长完全不生效；case_distribution 旧签名无 p_case_id |
| ③ | abandoned 口径 | 61 个 status='active' 会话全部计入"中途退出"：其中 53 个停滞超 2 小时、8 个为 2 小时内活跃（进行中被误判为退出） |
| ④ | 心跳归并 | 实测区间 sum=30s/max=10s：30 秒心跳 > 10 秒区间 + 5 秒归并窗口，每次心跳都新开 10 秒区间，时长系统性低估；无区间上限 |
| ⑤ | detail 白名单 | 实际 detail 仅 path 键，但 RPC 无键白名单/长度限制，可夹带任意内容；页面/CSV 无"非防篡改"声明 |
| ⑥ | 账号隔离 | 探针（统计探针A*）/联调（dbg/routeB）/E2E（E2E测试学员/quiz-test）与真实学生同池，仅靠 join profiles 无法区分；历史账号无法判定未标记 |
| ⑦ | 安全边界 | 四 RPC 已复用 app_is_teacher 白名单（双校验，无需修复）；csvEscape 无公式注入防护（=/+/-/@ 前缀可注入） |
| ⑧ | 统计维度 | 周活跃、题库薄弱项、单学生逐次训练明细未实现 |

### 修复内容

- **①时区**：统一按北京时间自然日（from = `p_from_date::timestamp - 8h`，to 含全天）；日/周趋势 `started_at + 8h` 分桶；zod 严格日历校验（拒绝 2026-02-31/2026-13-01，含 2024-02-29 闰年通过）+ `from<=to` 双层校验（zod 422 + RPC INVALID_DATE_RANGE）；
- **①跨日分摊**：activeHours 按 `greatest(started_at, from) .. least(ended_at, to)` 裁剪，跨日区间按重叠秒数分摊（裁剪算式已实测：10h→16h 窗口输出 21600s）；
- **②caseId 贯穿**：per_student/overall 的 activeHours 子查询补 case 条件（无会话归属的区间在 caseId 筛选时保守排除）；case_distribution 签名补 p_case_id；
- **③口径三分**：completed（已完成）/ in_progress（active 且 2 小时内有更新）/ abandoned（active 且停滞超 2 小时）——时间客观口径，不改历史数据；页面与 CSV 同步三分展示；
- **④心跳归并**：归并窗口 5s→45s（覆盖 30s 心跳 + 15s 抖动余量），心跳可正常续期区间；单区间封顶 3600s 防无界续期；多标签靠浏览器 visibility 语义天然去重（非当前标签不发心跳、隐藏即 idle），多浏览器窗口并行区间如实累计（口径已声明）；
- **⑤detail 白名单**：zod strict（仅 path 键、值 ≤256）+ RPC INVALID_DETAIL 双层校验；页面与 CSV 增补"非防篡改学习证据，正式成绩以考核记录为准"声明；
- **⑥账号隔离**：profiles 新增 `account_kind`（real/test/unknown，默认 unknown=历史无法判定）；**标记规则（2026-10-13 第二轮证据补全后）**：`test` 仅授予有受控创建证据的账号——即由 git 追踪的受控验收脚本（`verify-usage-stats.ts` 创建「统计探针A%」、`verify-usage-stats-deep.ts` 创建「统计深探针%`」）真实 signup 产生的探针身份（迁移 `20261013110000`/`20261013120000`）；`dbg`/`routeB` 等无受控创建溯源的历史账号一律回退 `unknown`（禁止按昵称前缀泛化标记）；`real` 目前 0 个（注册来源无法在 DB 侧可靠判定为真人，不做自动标记，如需确认由管理员受控 UPDATE）。当前 DB 实况：test=6（统计探针A×3 + 统计深探针×3）、unknown=7、real=0。统计 RPC 排除 test；unknown 如实包含并输出标记（页面"未验证"徽标、CSV"未验证"列）；预览演示身份不入库（既有隔离不变）；
- **⑦CSV 注入**：csvEscape 对 =/+/-/@/制表符/回车开头的值前置单引号（OWASP 建议）；
- **⑧补齐**：新增 `teacher_stats_weekly_trend`（周活，周一起始）、`teacher_stats_weak_areas`（题库薄弱项：样本 ≥3 且正确率 <0.8）、`teacher_stats_recent_sessions`（单学生逐次下钻，需指定学生，limit 1–100）；API `detailUserId` 参数 + 页面"查看"下钻。
