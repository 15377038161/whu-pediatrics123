# 教师学生使用统计——口径说明与验收记录

实施时间：2026-10-11
性质：最小实现（仅授权范围内：复用内置数据库与既有教师白名单，不推送发布，不新增第三方埋点）

## 一、数据模型（supabase/migrations/20261011100000_session_engagement_events.sql）

| 对象 | 说明 |
|---|---|
| `student_engagement_events` | 学生学习事件表：user_id / session_id(uuid, 可空) / event_type / occurred_at(服务端时间) / client_event_id(幂等键) / session_tab_id(多标签区分) / detail(脱敏元数据)。唯一约束 (user_id, client_event_id) 保证幂等 |
| `student_active_intervals` | 有效活跃区间表（服务端派生）：user_id / tab_id / started_at / ended_at / duration_seconds。无 INSERT/UPDATE 策略，只能由 RPC 派生 |
| `engagement_record_event()` | 受控事件上报 RPC（SECURITY DEFINER）：归属强制（auth.uid()）、会话归属校验（不能挂他人会话）、服务端时间、幂等去重、派生/续期活跃区间 |
| `teacher_stats_per_student / overall / daily_trend / case_distribution()` | 教师统计 RPC（SECURITY DEFINER，内部 `app_is_teacher()` 白名单 fail-closed）：明细 + 汇总 + 日活趋势 + 病例/模式分布 |

事件类型：`session_start` / `session_end` / `page_enter` / `page_leave` / `visibility_active` / `visibility_idle` / `heartbeat`。

## 二、有效时长口径

- 只统计**页面可见且活跃**的时间：`visibility_active` / `page_enter` / `session_start` / `heartbeat` 开启 10 秒最小活跃区间，同标签页 5 秒内的后续活跃事件归并续期；
- **隐藏页 / 切后台**（`visibility_idle`）、**离开页面**（`page_leave`）不驱动区间，区间自然截止；
- **多标签去重**：区间按 `tab_id`（sessionStorage 标签页 ID）独立计算，同浏览器多标签不重复累计同一时间片；
- **挂机不计入**：无心跳（30 秒间隔）则区间不续期；
- **不信任客户端时钟**：`occurred_at` 一律为数据库 `now()`，客户端时间仅存 detail 供排障；
- 心跳间隔 30 秒 + 归并窗口 5 秒：正常使用下区间连续，网络抖动 <5 秒不丢失，挂机 >35 秒不累计。

## 三、统计范围与测试数据分离

- 统计一律 join `profiles` 且 `app_role='student'`：RLS 探针（rls-probe-*）、联调账号（教师角色/无 profile）、新注册验证身份（usage-probe-*，display_name 标注统计探针）不进入教师统计；
- 预览演示身份（provider=preview）走进程内存不入库，事件上报接口直接返回不入库，与真实数据天然分离；
- 练习成绩（training_reports.total_score）输出处均带"非正式成绩"标识（scoreBasis: practice-only）。

## 四、API

| 接口 | 方法 | 鉴权 | 说明 |
|---|---|---|---|
| `/api/engagement` | POST | student | 事件上报：服务端身份+时间+幂等；返回 `{accepted, persisted}`（重复事件 accepted=false） |
| `/api/teacher/usage-stats` | GET | teacher | 统计查询：`from/to`（日期）、`userId`、`caseId` 筛选；`format=csv` 输出脱敏汇总（姓名/学号脱敏，无 user_id 明文、无患者数据） |

权限模型：学生调教师统计 403；未登录 401；学生直调统计 RPC 被拒（FORBIDDEN）；事件挂他人会话 403；RLS 行级隔离（学生只见自己的事件）。教师判定复用既有 `app_is_teacher()` 白名单（未修改白名单，未修改任何既有 RLS 策略）。

## 五、前端

- 学生端布局挂载埋点（`StudentEngagement`）：进入/离开/前后台切换/心跳；
- 训练页上报 `session_start`/`session_end`（挂载/卸载）；
- 教师端新页面 `/teacher/usage-stats`（教师导航"使用统计"）：汇总卡片、学生明细表、日活趋势、病例/模式分布、日期/学生/病例筛选、脱敏 CSV 导出（fetch+blob 下载）；空数据诚实展示"暂无数据"。
