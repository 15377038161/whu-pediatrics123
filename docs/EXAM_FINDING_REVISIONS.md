# 查体内容修订与候选版本

`src/domain/exam-finding-composer.ts` 按实际器材及部位编排固定教学所见。`exam-package-revision.ts` 只修订非原始的缺失或模拟所见，原始查体记录、测量数据、生长测量、评分点、证据编号和媒体保持原样。不同方法不互相冒充，局灶原文不升级为整个区域的精确结果。

缺失的非测量项目只有在部位适用、无已知局部异常及全身风险冲突时，才加入明确标记的固定正常教学设定。诊断中的休克、脱水等风险也参与判断。原始数值不能直接换算为耳温、额温等另一次新测量；年龄相关分级及缺失测量仍需独立制作，不能因为原文缺失就编读数。本轮不代表全部正确组合已经有独立患者结果。

## 私有制作与校验

```powershell
pnpm exec tsx scripts/training/revise-exam-findings.ts <已登记代次的私有上传目录> <不存在的新输出目录>
pnpm exec tsx scripts/training/verify-exam-revision.ts <旧代次上传目录> <候选目录> <私有验收JSON>
```

输入必须为已登记、校验大小和 SHA256 的内容包。输出保留 67 入口、53 来源、1042 媒体，复用三份已核验媒体归档；源文件按字节保留，全部非查体字段按结构对比保持一致。新目录已存在时拒绝覆盖；生成后重新解码验证，并逐例输出变化计数。`registered:false` 表示候选未登记，不能据此宣称服务器已安装。

全库工程脚本实际执行每项器材/部位操作及重复操作、每例错误配对，并在索引更新后回读所有旧会话绑定。它使用合成身份和现有引擎，不调用模型或写数据库，不代替 67 例真实师生验收及医学审核。

后续启用须按既有受控媒体安装流程：私有对象存储上传、登记新归档、verify-only、安装、真实新会话绑定、旧会话恢复核验。禁止上传私有内容到 Git，禁止覆盖旧代次或自动重绑旧会话。Word 与通关秘籍须随后按实际启用版本重新导出、渲染并核对，不沿用旧版本分数承诺。
