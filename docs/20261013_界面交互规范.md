# 本轮界面交互规范

沿用暖白、深绿与现有诊室背景，不重设计品牌。所有交互目标移动端至少44px；输入字号至少16px；键盘焦点可见；表格仅在组件容器滚动；长标题折行或省略，不扩大整页宽度。

主路径为接诊→问查→诊断处置→沟通→报告→下一病例。已提交数据自动保存；未提交草稿在同会话切换阶段保留，离开/刷新须提示。普通已保存会话退出不重复确认；OSCE退出说明计时仍继续。

加载、空状态、失败分别显示。训练加载失败可原请求重试，鉴权失败沿用既有清会话流程。CSV和二进制请求统一authedFetchRaw；日期一律使用Asia/Shanghai格式化工具。

解剖页按实际二维部件示意命名，不宣称真实3D。语音预留不出现在界面，无失效按钮。

页面清单：登录、认证错误、学生首页/病例库、专项、OSCE、训练、题库、报告列表/详情、解剖示意、教师首页、学生会话详情、病例资料详情、病例草稿与发布、使用统计、智能体介绍。以390/768/1440宽度浏览器截图和溢出检查为验收；合成API响应测试验证前端布局与交互，不代表真实身份或数据库验收。
