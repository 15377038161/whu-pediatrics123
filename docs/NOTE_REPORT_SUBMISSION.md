# 病历提交与训练报告

嵌入接诊页的“提交病历并生成训练报告”与“提交病历”共用提交逻辑。先保存草稿，POST `/api/notes` 成功后才调用既有 `/api/sessions/[id]/finish`。仅保存草稿不代表正式提交。

空病历不可提交；必填段缺失时先提示并由学生确认，简答仍可提交。同步锁拦截重复点击；网络失败保留 clientEventId 供幂等重试。已成功提交且内容未变化时复用当前版本，刷新从最新提交恢复，不增加重复版本。内容改变后生成新提交编号。失败保留编辑内容，提交失败不生成报告；报告失败可重试，不重复提交病历。不改历史报告或正式评分。
