# 训练页真实验收与修复

线上真实授权账号验收发现：一例真实来源病例能创建并刷新恢复，但响应只含手卫生目录、四项生命体征为空、检查目录为空。检查申请实测返回 `/api/agent/turn` HTTP 409 / INTERNAL_ERROR，不能判定完整接诊可用。对应本地受控来源具有生命体征、查体和检查记录，线上绑定版本与本地当前版本不同；需安全导入、回查后新建会话，旧会话保持原绑定。

本批代码处理：

- 活动目录仅保留67个真实来源入口，移除两例合成演示病例以及内容导航、对应OSCE发布入口。历史定义保留，历史会话只读，不再新建训练。
- 历史引擎单元测试在各自测试进程显式注册合成夹具，生产目录不导入这些测试文件。独立退役测试验证67入口、旧ID拒绝新建且历史定义仍可读。
- 移除训练页底部整包病例资源浏览器。训练中的附件只使用已实现的对应检查/查体结果媒体组件，教师原始资料仍由教师病例页查看。
- 语音输入入口始终可发现，ASR与TTS分别判断；TTS失败不再隐藏可用ASR。未就绪时显示状态，实际录音仍使用原有录音、转写、确认流程。
- 病例说明默认折叠，移除人物区域重复说明。

材料安装、线上复测、真实麦克风及最终部署须分别记录。构建或资料图片解码成功不能替代正确病例版本、附件归属及流程验收。原件缺失数值不得生成正常值补齐。
