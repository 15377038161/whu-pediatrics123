# 学生首页与九宫格病例库

按教师手绘布局：桌面左侧为首页、专项、OSCE、题库、报告；右上角保留本人头像、姓名与退出。主要内容仅保留训练横幅和病例库，移除旧版流程条、重复训练入口大卡片及首页能力评分区。报告仍从导航进入；我的班级、儿童骨骼入口放在病例库标题旁。

## 浏览与训练

- 每页 9 个病例，手机、平板和桌面均为三列。小屏卡片以学科、完整主诉为主，不截断主诉；不把完整桌面布局直接等比缩小。
- 搜索病例／症状／系统与学科筛选常显；资料来源筛选、最近选择折叠保留。切换搜索或筛选后回第一页。
- 点击整张卡片进入既有引导训练，不再显示单独接诊按钮。标题使用真实链接覆盖卡片点击区域，支持键盘回车、新标签打开；“更多”在独立交互层，展开或选择模式不会误触默认接诊，保留资料说明、沉浸式教学与 OSCE 入口。OSCE 可用性仍服从现有资料完整性门控。
- 支持上一页、页码、下一页及输入页码跳转；页码范围以筛选后的结果为准。编号输入不允许空值、小数或越界。
- 上次进度独立加载，失败提示重试而不阻塞病例库。存在有效训练时提供继续上次；开始训练走现有服务端随机接诊，病例发布、资料与幂等规则不变。
- 学生目录仍经 `/api/cases` 发布过滤；不新增病例事实请求，不把诊断答案或检查结果放入卡片。

## 验证

运行 `pnpm validate`、`pnpm build`。既有分类测试覆盖搜索、筛选、空结果、越界、用户最近选择隔离；新增相邻九宫格页面无重复及末页完整性验证。

浏览器须在 390／768／1440px 确认三列、每页最多 9 卡、无页面横向溢出、主诉完整、按钮可操作；验证搜索清空、筛选重置页码、跳页边界、继续训练及各模式链接。真实登录与线上部署结果须另记，不能以静态截图代替。
