# 完成训练后的综合复盘

报告页新增“AI 接诊综合复盘”。学生点击生成一次，服务端使用 `COZE_AI_REPORT_MODEL`（默认 `doubao-seed-1-8-251228`），开启 thinking，单次等待上限 90 秒、应用层一次调用、SDK 不重试。读取报告不会自动消耗模型额度；失败后由学生主动重试。

输入包括本会话实际消息、操作、报告生成时冻结的诊疗提交、与原始版本匹配的正式病历，以及已保存的教学反馈。没有绑定参照的历史报告不借用当前病例答案。只接收七个独立环节、最多五条优先改进建议；引用必须逐字存在于所指证据，模型输出的新分数字段会被拒绝。

## 接口与权限

- `GET /api/reports/[id]/review`：沿用报告及会话权限，返回已保存复盘或 null。教师可以读取有权查看的学生复盘。
- `POST /api/reports/[id]/review`：仅训练本人可发起；必须为 completed，会话关联报告及原始/教学版本必须一致。进行中返回 422，非本人返回 403。解析、引用或保存失败返回 503，原报告不受影响。
- 同一进程中同一用户及报告的并发生成合并；已保存且版本匹配时直接复用，不再次调用模型。多实例并发仍可能产生重复模型调用，不宣称分布式 exactly-once。

复盘作为 `SessionState.postVisitReview` 保存在既有 `training_sessions.state`，包含报告 ID、双版本、输入摘要、模型、提示词版本与时间；不更新原训练活跃时间、不改 training_reports、能力画像、积分或选关。写入只更新本人 completed 行的 state。学生训练接口投影删除此字段，只通过完成后的报告接口读取。没有新增账号、表、RLS 或权限。

## 教学边界与验证

模型负责解释，不负责改分或新增患者事实。逐项核心表达和检查选择理由继续来自固定 `teachingFeedback`；历史材料不足时如实展示局限。引用校验只能保证所引原话存在，不能证明推理医学正确，输出仍需医学审定。

单测覆盖完成态、归属、双版本、七环节、伪造引证、新评分拒绝、并发合并、保存及复用、异常不改分。合成 SDK 调用不能替代真实模型和实际数据库重启验收；真实验证状态记录于私有 outputs 断点。

回环 UI 适配器对该接口 GET 返回 null、POST 返回明确不可用，不将普通报告对象误当作综合复盘，不模拟真实模型成功。会话 state 沿用原有本人写权限，综合复盘是教学建议，不宣称为防篡改的正式考核证据。
