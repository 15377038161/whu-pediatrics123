# 沙箱环境复建指南（dev server 持久启动 + 浏览器验收环境）

> 目的：沙箱会话恢复或 `/tmp` 被平台定期清理后，一条命令复建验收环境。所有命令与路径均来自
> `dev-restart.log` 与运行进程的实证（不猜测），验收口径见 `验收记录.md` 第七节「环境突破」与第十一/十二节。

## 一、dev server 持久启动

实证命令（`dev-restart.log` 与 `ps`）：`pnpm run dev` → `next dev -H 0.0.0.0 -p $DEPLOY_RUN_PORT`
（当前 5173）。平台托管的 `coder dev` 退出后由项目脚本自管：

```bash
bash scripts/sandbox-dev-restart.sh status    # 查看状态（pid + GET / 探活）
bash scripts/sandbox-dev-restart.sh           # 重启：停旧监听进程 → nohup 后台启动 → 120s 探活
```

- 日志固定落 `dev-restart.log`（项目标准日志目录，勿写 /tmp）。
- 端口检测用 `netstat -tlnp`（本沙箱无 `ss`/`fuser`/`lsof`，实测 netstat 可用）；端口后接空白锚定，
  仅杀 LISTEN 进程，绝不触碰 9000 系统端口。
- 平台环境变量（`CODER_SUPABASE_URL/ANON_KEY/TENANT_ID` 等）由沙箱进程自动继承，无需配置。

## 二、浏览器验收环境复建（/tmp，会被定期清理）

沙箱无 root、无系统浏览器。环境 = playwright-core + chromium-headless-shell + 28 个 bookworm
deb 解包共享库 + 字体，全部在 `/tmp`（清理后重跑脚本即可）：

```bash
bash scripts/rebuild-browser-env.sh           # 幂等（已有产物跳过）；--force 全量重建
source scripts/browser-env.sh                 # 导出运行验收脚本所需环境变量
```

产物布局与实证路径一致：

| 路径 | 内容 | 对应环境变量 |
|---|---|---|
| `/tmp/pwtest/node_modules/playwright-core` | playwright-core 1.56.1 | `PW_CORE_PATH` |
| `/tmp/pw-browsers/chromium_headless_shell-1194` | Chromium Headless Shell 141.0.7390.37 | `PLAYWRIGHT_BROWSERS_PATH` |
| `/tmp/pw-libs/usr/lib/x86_64-linux-gnu` 与 `/tmp/pw-libs/lib/x86_64-linux-gnu` | X11/nss/glib 等与 dbus 等解包库 | `LD_LIBRARY_PATH`（两个目录都必须含） |
| `/tmp/pwtest/fonts.conf` | 字体配置（Liberation/DejaVu/文泉驿微米黑） | `FONTCONFIG_FILE` |

注意：
- playwright-core 版本 1.56.1 与浏览器 build v1194 绑定，勿单独升级。
- `libdbus-1.so.3` 落在 `lib/x86_64-linux-gnu` 而非 `usr/lib/...`——`LD_LIBRARY_PATH` 少任一目录
  浏览器启动即报 `cannot open shared object file`（复建脚本自检已覆盖此坑）。
- 脚本末尾自检：真实启动浏览器渲染 `data:` 页面，不依赖应用服务与凭据。

## 三、运行浏览器验收脚本

```bash
# 1. dev server 就绪（见第一节）
bash scripts/sandbox-dev-restart.sh status

# 2. 浏览器环境就绪 + 环境变量
bash scripts/rebuild-browser-env.sh
source scripts/browser-env.sh

# 3. 凭据文件（键值对文本：email=.../password=...，仅既有演示学生账号，权限 0600）
export BROWSER_CRED_FILE=/path/to/cred

# 4. 运行（BROWSER_BASE_URL 默认 http://localhost:$DEPLOY_RUN_PORT，截图默认 artifacts/browser-acceptance）
node scripts/verify-browser-entries-ui.mjs     # OSCE/沉浸式/解剖/题库（双视口 38 项）
node scripts/verify-browser-tests-ui.mjs       # 查体+辅助检查 UI 闭环（双视口 44 项）
node scripts/verify-browser-interactive.mjs    # 主验收（双视口）
node scripts/verify-browser-backdrop.mjs       # 遮罩修复回归
node scripts/verify-font-rendering.mjs         # 中文字体渲染
```

## 四、退出码与证据保存规范

- 验收脚本运行必须重定向保存原始进程退出码与断言计数，禁止 `tail/head` 管道掩盖退出码：

```bash
node scripts/verify-browser-entries-ui.mjs > artifacts/entries-rerun.log 2>&1
echo "EXIT_CODE=$?" >> artifacts/entries-rerun.log
grep -E "^# (pass|fail)|EXIT_CODE" artifacts/entries-rerun.log
```

- 失败时按日志排障优先级：`app.log`/`dev-restart.log`（后端）→ `console.log`（前端）→ `dev.log`。

## 五、边界与提醒

- `/tmp` 为临时目录，平台会定期清理——这正是本指南存在的原因；每次会话恢复后先跑第二节脚本。
- 复建脚本下载源：`cdn.playwright.dev`（浏览器）与 `deb.debian.org`（bookworm deb，版本号已固化
  于脚本内 28 条 pool 路径），任一不可达会显式 FAIL 并保留日志（`/tmp/pw-browser-dl.log` 等）。
- 零账号新建/改密：浏览器脚本仅注入既有演示学生会话（界面条件测试手段，非完整登录验收）；
  教师端预热等需教师凭据的操作走 `PEDIATRICS_TEACHER_EMAIL/PWD` 环境变量或 `--cred-file`，fail-closed。
