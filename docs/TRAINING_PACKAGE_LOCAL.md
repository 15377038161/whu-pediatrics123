# 本地67例教学包：运行与边界

本轮不发布线上，不导入线上病例，不重算历史成绩。源文件仍在 `knowledge/teaching-cases`；新教学包安装在私有目录 `knowledge/training-packages`。53个独立来源对应67个入口，14个关联入口单独成稿并说明名称、上位病种或亚型差异，不能视为14名新患者。

## 本地运行

已有依赖时，在项目根目录运行：

```powershell
$env:NEXT_DIST_DIR='.next-training'
pnpm build
pnpm exec next start --hostname 127.0.0.1 --port 8775
```

打开 `http://127.0.0.1:8775/`，通过现有合法身份登录，再创建新训练。默认 `.next` 和既有本地服务不覆盖。已开启的旧会话不自动升级教学版本，需要新建会话体验新版内容。

教学包根目录可由 `PEDIATRICS_TRAINING_PACKAGE_ROOT` 覆盖。默认目录结构：

```text
knowledge/training-packages/
  index.json                 # caseId → 当前教学版本
  packages/<version>.json    # 私有病例包，不可修改既有版本
  media/<sha256>.png         # 仅已释放媒体可经鉴权接口读取
```

资料包中的 `runtime` 可安装到上述目录。应用仍需已有原始病例资料；教学包不会自行替换数据库绑定的原始版本。源版本不匹配或包损坏时拒绝套用，继续原版本流程。不要为显示新版而改绑线上病例。

## 已实现的路径

- 问诊使用完整的允许披露事实、近期对话及话题记忆，模型返回角色台词与事实编号；校验数值、关键否定、病例归属和表达能力后记录实际披露。数值遗漏仅记部分证据；未表达的引用不计分。原始段落编号继续解释旧记录，新包使用细分编号。
- 解释与病史追问共用角色交流入口，提交处置计划后仍可继续补问。连续几句简短解释累计进入沟通评分；问诊追问不会覆盖先前解释。单纯安抚、确认理解和复述医生话语不作为新的病史采集证据。
- 查体目录独立于阳性答案。拿起任意器材→点击人物大部位→在局部图点击具体位置执行；也可先定位再选器材；支持患者左右、前后面和实际体位。站立/仰卧人物素材与坐位、侧卧、俯卧的实际体位分开；没有相应人物姿势图时明确显示既有参考图体位，不能用站立图冒充侧卧。查看后面不会完成翻身；仰卧不能直接取得后背结果。
- 腋下电子体温计、额温枪、耳温计分别匹配部位。同一条原始体温可由合适方式回看，但不冒充三次新实测，也不要求重复三种测温方式得分。
- 检查结果在本地版本中预先固定，原图、报告图、模拟图分别标明。资料不充分时给出有用的评估和参考信息，不编造患者数值。检查选择的必要性在结束后的反馈展示。
- 数值检查同时展示指标、原始值、原单位和原时点表格。重复申请只回看同一版本，不视为一次新测量；最终反馈说明重复次数及申请目的，合理的病情监测不因此被自动判为多余。
- 新量表为本地教学练习反馈：基础80、提高20。保留原过程分/正式成绩字段；材料缺失、读取故障和不可可靠判定项不作为学生0分。合理简答和已登记同义词可得分，缺必要条件给半分，关键不安全表达单独处理。

## 工程验证与真实验收的区别

`scripts/training/ui-fixture-server.ts` 是仅监听127.0.0.1的浏览器验收适配器，调用真实既有引擎和投影，使用合成身份、进程内会话，不读写线上数据库。浏览器经8875回环代理连接它和8876的真实页面；它不是新的登录方式，不能据此宣称真实登录或数据库持久化验收完成。

本机未配置模型服务时，`validate-dialogues.ts` 会如实记录 `model_fallback / not_configured`。需在本机安全环境中按原有服务配置模型凭据后重新运行；不要在聊天或命令参数中粘贴密钥。脚本只输出执行方式与计数，完整对话保留在受控 `outputs` 中。

内容均标记为自动整理、未医学审定。原诊疗经过可能包含特定时点和条件，不作为当前患者的处方。规则评分具有可解释性，但不是任意自由文本的完整医学语义评审；未登记的合理替代方案应由教师结合提交原文复核，不把规则未识别等同于临床错误。

真实登录、多身份数据库持久化、真实模型自然度和物理麦克风/移动设备语音按验收记录单列。本轮未重新测试这些外部条件，也未恢复、检索或新建任何凭据。
