# 诊断依据与本轮记录关联

2026-10-28，本地实现、尚未发布。用于接诊结束后的具体依据追溯，不代表全部逐病例临床质量反馈已完成。

诊断阶段可选择实际用到的问诊、查体和检查记录，并在原有诊断依据文本中说明支持/排除关系。无需全选；接诊时已知但未形成操作事件的信息仍可写在依据中。仅有准备、技术失败、未回报或未获得事实的操作不能成为关联选项。

`SUBMIT_DECISION.data.linkedEventIds`为可选的原事件ID列表，最多128项，每项最长80字符。服务端逐项确认属于当前会话、为真实临床记录且事实已经取得；不信任客户端声明的获取状态，伪造/他会话/未解锁/准备项一律整次拒绝，拒绝前不保存诊断或追加提交事件。原客户端省略该字段仍可用。

报告冻结关联事件的摘要、原ID、病例和来源版本，明确区分已关联、未关联及无法还原。选项数量、选中动作或提交非空不产生额外临床分，不替代证据解释质量判定。旧报告不回算，缺少该字段的旧提交不追溯归为缺陷；历史定位损坏时不编造证据。学生不会因此获取尚未释放的信息或完整标准病历。

提交与报告中的关联数组均独立复制，后续修改会话草稿不改变旧报告。报告的原始诊断依据文本保留；具体诊断、鉴别与处置是否合理仍须逐病例评价判据，尚未因本功能而宣布完成。没有新增AI评分、身份、RLS或数据库表。
