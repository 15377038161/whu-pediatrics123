# 语音预留与音效边界

本轮仅提交src/domain/speech-contract.ts：ASR/TTS输入输出类型、统一错误、取消信号以及冻结的unavailable能力状态。没有provider实现、HTTP端点、权限申请、录音、播报、依赖或密钥。未来实现需明确用户授权、接入服务、鉴权、隐私与配额，不能以此说明声称语音可用。

工作台不显示语音入口。查体结果仅在存在真实听诊音频时显示重播按钮，普通文本结果没有“语音重播”假入口。真实听诊音效与资料视频沿用既有路径。

验证：speech-contract单测检查运行时只导出能力状态、无默认实现；工作台交互浏览器检查以及构建验证客户端边界。
