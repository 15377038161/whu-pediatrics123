# 珞珈儿科智训 · UI 设计规范

> 文档版本：v1.0 ｜ 日期：2026-08-27 ｜ 设计方向：方向 B · 童趣守护
> 适用范围：学生端 / 教师端 / 公开页 全部界面，移动端优先、桌面端适配
> 配套文档：功能测试记录、设计优化说明文档、用户操作动线与可用性验证

---

## 1. 总则与设计原则

| # | 原则 | 落地要求 |
|---|------|----------|
| P1 | 动线最短 | 核心操作 ≤3 步触达：首页→病例→训练；报告→补练一键直达 |
| P2 | 一致性 | 同一操作在任何页面用同一交互（返回=左上‹、确认=右下主按钮） |
| P3 | 可解释 | 所有评分/反馈附证据入口，异常态说明原因与出路 |
| P4 | 容错 | 破坏性操作（退出训练、交卷）必须二次确认；进度自动保存 |
| P5 | 状态可见 | 页面/按钮/数据五态齐备：normal / hover / active / disabled / empty-error |

**一致性目标**：全平台色板、字阶、圆角、间距 100% 引用设计 Token；组件复用率 ≥90%。

## 2. 界面布局结构

### 2.1 移动端（390 基准，单列 App 流）

```
┌───────────────────────┐
│ 顶栏（56pt）           │ ← 返回‹ ｜页面标题｜右侧动作（徽章/更多）
├───────────────────────┤
│                       │
│   内容区（垂直滚动）     │ ← padding 16，模块间 gap 16
│   顺序：hero → 筛选 →  │
│   列表/卡片 → 操作      │
│                       │
├───────────────────────┤
│ 底部导航（56pt+安全区） │ ← 学生4项 / 教师3项，激活主色
└───────────────────────┘
```

- 顶栏固定，滚动时不消失；标题居左 18pt Bold。
- 弹层类操作（训练中断确认）用**全屏遮罩 + 居中卡片**，遮罩 Ink 92%。
- 沉浸式训练台**无底部导航**，避免误触退出，退出须经确认弹层。

### 2.2 桌面端（≥1024，左导航 + 主工作区）

```
┌────────┬──────────────────────────────┐
│ 侧边栏  │  主工作区（padding 24，gap 16）│
│ 220pt  │  ┌────────┐ ┌─────────────┐ │
│ 品牌    │  │ 患儿面板 │ │  对话/表单面板 │ │
│ 导航5项 │  │  360pt  │ │  弹性填充     │ │
│ 用户卡  │  └────────┘ └─────────────┘ │
└────────┴──────────────────────────────┘
```

- 侧边栏常驻：品牌（主色）、5 项导航（激活项浅蓝底+主色字）、底部用户卡。
- 训练台采用**双面板**：左患儿（体征+查体热区+阶段步骤）固定 360pt，右对话弹性填充。
- 首页桌面采用「病例网格 + 能力卡」双栏（见屏 `3:715`）。

### 2.3 栅格与安全区

- 间距基准：4pt 栅格（4/8/12/16/24/32）。
- 移动端内容左右 padding 统一 16；卡片内 padding 14–16。
- iOS 安全区：底部导航预留 34pt；顶栏不做刘海避让（固定 56pt）。

## 3. 信息层级划分

| 层级 | 角色 | 视觉规格 | 示例 |
|------|------|----------|------|
| L0 | 页面主任务 | Display/H1 + 主色实底按钮 | 「进入病例」「开始考核」 |
| L1 | 关键数据 | H2 + 强调色数值 + 卡片容器 | 六维能力分、总分 86 |
| L2 | 结构分组 | H3/节标题 15 Bold + 分区间距 24 | 「推荐练习」「考核规则」 |
| L3 | 辅助说明 | 12–13pt 灰 `#6B7280` | meta 行、提示文案 |
| L4 | 状态反馈 | Badge/Chip 11–12pt | 难度、模式、进行中 |

**每屏只有一个 L0**；同屏高饱和色（主色+辅色）≤2 个；告警暖色仅用于限时/失分场景。

## 4. 交互逻辑定义

### 4.1 导航模型
- **层级导航**：顶栏左‹ 返回上一级；禁止跨层级跳转（报告详情→病例库必须经返回）。
- **平级切换**：底部导航（学生：首页/病例/报告/我的；教师：学情/会话/设置）。
- **角色分流**：OAuth 成功后按 role 一次性分流，无手动选择。

### 4.2 状态与数据模型绑定
- 页面状态直接消费 `SessionState`（stage/status/mode）与 `TrainingReport`（status）。
- `status: active→report_pending→completed` 映射 UI：训练中 → 生成中 → 可查看。
- OSCE `expiresAt` 驱动倒计时；归零触发**自动交卷**（不可逆，需时间到提示页）。

### 4.3 反馈模型
| 事件 | 反馈形式 | 时效 |
|------|---------|------|
| 发送问诊 | 气泡右置上屏 + 输入清空 | 即时 |
| AI 提示点击 | 对话区插入浅蓝提示条 | 120ms 淡入 |
| 阶段推进 | 步骤条脉冲变色 + 顶部 toast | 200ms 缓动 |
| 交卷/提交 | 全屏结果态（时间到页/报告页） | ≤1s 跳转 |
| 危险操作 | 遮罩+弹层（继续/退出） | 阻塞式 |

### 4.4 输入规范
- 问诊为**自由文本**，支持语音转写入口；禁用选择题式预设答案。
- 「AI 提示」仅给方向不代答，每阶段最多 3 次（防依赖）。
- 表单（诊断/处置）提交前校验必填，错误内联提示 12pt 红 `#E26D6D`。

## 6. 响应式适配方案

### 6.1 组件行为矩阵（核心组件 × 断点）

| 组件 | Mobile | Tablet | Desktop |
|------|--------|--------|---------|
| 导航 | 底部导航 | 底部导航（可收起） | 左侧固定侧边栏 |
| 病例/报告卡 | 单列 | 2 列网格 | 3–4 列网格 |
| 训练台 | 单列（患儿卡折叠为横条） | 单列+加宽留白 | 双面板（患儿 360pt + 对话弹性） |
| 六维能力 | 纵向评分条 | 纵向 | 雷达图/横向双列 |
| 对话气泡 | 全宽气泡 | max-width 80% | max-width 65% |
| 表格（教师） | 卡片化列表 | 2 列 | 完整表格 |

### 6.2 移动端专项
- 390 基准设计，向 320–428 自适应（文字不截断、按钮不换行）。
- 触控目标 ≥44×44pt；底部导航图标+文字双层。
- 训练台顶栏显示阶段进度条替代完整步骤条，防横向滚动。

### 6.3 桌面端专项
- 内容区 max-width 1280 居中，超大屏留白扩展。
- 键盘可达：Enter 发送问诊、Esc 关闭弹层、Tab 焦点环 2px 主色。
- 患儿 SVG 热区悬停显示部位名称（title 提示），点击查体同移动端。

## 7. 异常与分支状态规范

| 状态 | 视觉 | 文案原则 | 出路（必须给） |
|------|------|----------|----------------|
| 空状态 | 圆形图形+灰字 | 说明「为什么空+怎么办」 | 主按钮引到内容源（如「去训练」） |
| 加载中 | 骨架屏/计时圈 | 不阻塞认知 | 超时 3s 出重试 |
| 错误态 | 暖色/红色语境 | 用户语言+错误码小字 | 重试 + 返回 |
| 限时态 | 倒计时暖色脉冲 | 最后 30s 强提醒 | 到点自动交卷+说明 |
| 中断确认 | 遮罩+弹层 | 说明后果+保底承诺 | 继续为主按钮，退出为次 |

## 8. 可访问性基线（WCAG AA）

- 正文对比度 ≥4.5:1（Ink on BG ≈ 12:1 ✓；主按钮白字 on Primary ≈ 2.6:1 → **仅用于 ≥15pt 粗体**，小字场景加深主色 `#2E93C4`）。
- 全键盘操作；焦点环可见（见 §6.3）。
- 图标按钮配 ARIA label；色盲场景下状态不单靠颜色区分（附图标/文字）。
- 动效尊重 `prefers-reduced-motion`。

## 9. 一致性检查清单（开发走查用）

- [ ] 色值/字阶/圆角/间距全部来自 Token，无硬编码
- [ ] 每屏仅 1 个 L0 主任务
- [ ] 返回、确认、取消行为与 §4.1 一致
- [ ] 每个列表页有对应空状态；每个提交动作有加载/错误态
- [ ] 弹层均有遮罩且 Esc/点遮罩不直接破坏（训练中断弹层除外：点遮罩=继续训练）
- [ ] 移动端 320 宽与桌面 1280 宽双向走查无截断
- [ ] 触控目标 ≥44pt；对比度抽查通过
