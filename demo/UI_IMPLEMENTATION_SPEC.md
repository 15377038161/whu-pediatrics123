# 珞珈儿科智训 UI 实施规范 V0.2

## 设计方向

- 主题：珞珈书院感与临床工作台结合。
- 结构色：武大深蓝 `#073B63`；状态色：临床青绿 `#0F837D`；提醒色：克制橙 `#D56A35`。
- 背景采用低对比米白和细线纸张纹理，不使用紫色渐变、悬浮数据卡堆叠或通用AI插画。
- 儿科属性通过圆润但克制的触控组件、线描患儿示意和温和反馈体现，不卡通化病理信息。

## 统一尺寸

- 正文基准：15px；辅助文字：10—12px；页面标题：25px；模块标题：16—24px。
- 主按钮、输入框、器材按钮：最小高度48px；紧凑触控项：最小高度44px。
- 通用按钮圆角12px；内容容器圆角18px；重点病例卡圆角24px。
- 手机页面水平留白16px；桌面页面水平留白38—52px。

## 多端行为

- 手机：顶部返回/首页、底部五项导航；临床工作台从底部上拉，背景锁定且可点击遮罩关闭。
- 平板：保留移动导航逻辑，卡片由单列自然扩展为双列或四列。
- 桌面：隐藏移动导航，显示固定侧栏和顶部操作区；训练页展开为问诊、临床操作双栏。
- 断点：700px、1024px、1440px；不得产生页面级横向滚动。

## 核心交互规则

- 问诊角色由智能体动态决定，不提供固定患儿/家长切换按钮。
- 学生干预会改变后续应答顺序、插话行为和情绪状态，并留下过程证据。
- 查体器材与部位不匹配时不返回深层体征；正确匹配后更新生命体征、病例风险和评分证据。
- 教师端只提供查询入口；任务发布、参数修改和评分修改不出现在UI中。
- 每个页面均可通过移动端首页键或桌面侧栏回到首页；训练页提供保存、重置和完成按钮。

## 验收要求

- 320、390、768、1024、1440px视口宽度下，页面 `scrollWidth` 不得超过 `innerWidth`。
- 所有可见按钮可点击，底部导航和临床操作台不得遮挡输入框或核心内容。
- 完整流程必须可从问诊运行至OSCE报告；错误查体组合、未完成必填项和安全风险必须有明确反馈。
- 支持键盘焦点样式、`prefers-reduced-motion`，动态消息使用 `aria-live`。
